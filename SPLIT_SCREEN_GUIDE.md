## 🚀 **HOW TO USE SPLIT-SCREEN:**

### **VERTICAL SPLIT (Columns) - Your #1 Choice:**
1. **Open your first file** (e.g., Chapter 1)
2. **Right-click the file tab** → **"Split Right"** OR
3. **Keyboard shortcut**: `Cmd+\` (Mac) or `Ctrl+\` (Windows)
4. **Open second file** in the right panel (e.g., Composer/AI chat)
5. **Perfect for**: Composer on left, Text Editor on right

### **HORIZONTAL SPLIT (Rows) - Alternative:**
1. **Open your first file**
2. **Right-click the file tab** → **"Split Down"** OR  
3. **Command Palette**: `Cmd+Shift+P` → "View: Split Editor Down"
4. **Perfect for**: Text editor on top, Composer on bottom

### **QUICK SWITCH BETWEEN SPLITS:**
- **Focus left panel**: `Cmd+1` (Mac) or `Ctrl+1` (Windows)
- **Focus right panel**: `Cmd+2` (Mac) or `Ctrl+2` (Windows)
- **Focus top panel**: `Cmd+3` (Mac) or `Ctrl+3` (Windows)
- **Focus bottom panel**: `Cmd+4` (Mac) or `Ctrl+4` (Windows)

## 🎯 **KEYBOARD SHORTCUTS FOR WRITERS:**

- **Split Editor Right**: `Cmd+\` (Mac) / `Ctrl+\` (Windows)
- **Split Editor Down**: `Cmd+K Cmd+\` (Mac) / `Ctrl+K Ctrl+\` (Windows)
- **Close Editor Group**: `Cmd+K W` (Mac) / `Ctrl+K W` (Windows)
- **Move Editor to New Group**: `Cmd+K Cmd+Shift+\` (Mac) / `Ctrl+K Ctrl+Shift+\` (Windows)
- **Focus Next Group**: `Cmd+K Cmd+→` (Mac) / `Ctrl+K Ctrl+→` (Windows)
- **Focus Previous Group**: `Cmd+K Cmd+←` (Mac) / `Ctrl+K Ctrl+←` (Windows)
