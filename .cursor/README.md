# Walk This Way — Cursor Config

This folder holds **live agent configuration only**. Do not store archives, chat exports, or novel drafts here.

## What belongs here

| Path | Purpose |
|------|---------|
| `rules/` | AI behavior rules (`.mdc`) |
| `commands/` | Slash commands |
| `scripts/` | Automation scripts (non-ACE) |
| `config/` | `mcp.json`, settings, prompts |
| `hooks.json` | Event hooks (empty unless configured) |
| `notepads/` | Cursor notepads |
| `templates/` | Writing templates |

## Where everything else lives

| Content | Location |
|---------|----------|
| Project docs | `docs/project/` |
| Session notes & cleanup history | `docs/archive/session-notes/` |
| Setup guide copies | `docs/archive/setup-guides/` → see `docs/setup/README.md` |
| Chat history exports | `docs/archive/chat-history/` |
| Desktop pre-reconfig archive | `yy_Archive/Desktop_PreReconfig_2026/` |
| Other novel projects | `yy_Archive/Other_Projects/` |
