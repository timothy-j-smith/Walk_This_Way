# Session Start - Quick Wins Setup
## Automated Session Setup

**Command:** `/session-start` or `/start-session`

**Action:** Automatically offers to run Quick Wins session setup checklist.

**Usage:** 
- Type `/session-start` in Cursor Chat
- OR Claude will automatically offer this at the beginning of new sessions (see meta-instructions.md)

**What It Does:**
- Reminds you to pin Story Bible, Directives, and Current Chapter
- Provides quick access to guides and templates
- Ensures Quick Wins are set up for the session

**Automation:** Claude automatically offers this at session start - you don't need to remember!
