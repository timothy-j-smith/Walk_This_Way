# Character Report
## Character Mention and Voice Analysis

**Command:** `/character-report <name>` or `/char <name>` or `/character <name>`

**Action:** Shows character mention report and voice consistency analysis.

**Usage:** Type `/character-report Nick Johnson` in Cursor Chat.

**What It Shows:**
- Total character mentions by chapter
- Voice consistency check
- Character development tracking

**Script:** `.cursor/scripts/character_report.sh`

**Example:**
- `/character-report Nick Johnson`
- `/character-report Jackie Marsh`
- `/character-report Maxanne Sartori`
