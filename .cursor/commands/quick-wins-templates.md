# Quick Wins Templates
## Open Template Library

**Commands:** `/quick-wins`, `/templates`, or `/quick-wins-templates`

**Action:** Opens `.cursor/rules/quick-wins-templates.md` for quick access to all templates.

**Usage:** Type any of these commands in Cursor Chat to get instant access to all Quick Wins templates:
- `/quick-wins`
- `/templates`
- `/quick-wins-templates`
