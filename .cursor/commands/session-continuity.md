# Session Continuity Check
## Where Did We Leave Off?

**Command:** `/session-continuity` or `/where-were-we` or `/continuity`

**Action:** Shows where you left off last session and what's next.

**Usage:** Type `/session-continuity` in Cursor Chat for detailed session continuity analysis.

**What It Shows:**
- Last written location
- Next target scene/chapter
- Open plot threads
- Character development status
- What's ready for next session
