# Git Status Check
## Remind to Commit Your Work

**Command:** `/git-status` or `/git` or `/commit-check`

**Action:** Checks Git status and reminds to commit if needed.

**Usage:** Type `/git-status` in Cursor Chat to check if work needs to be committed.

**What It Shows:**
- Uncommitted changes
- Files modified
- Reminder to commit
- Remote sync status

**Script:** `.cursor/scripts/git-status-check.sh`
