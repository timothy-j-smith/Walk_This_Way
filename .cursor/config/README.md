# .cursor/config/ - COMPASS Configuration Files
**Purpose:** Organize all JSON configuration files for consistent structure

---

## 📋 CONFIGURATION FILES

All `.json` configuration files for COMPASS are organized here for:
- Easy access
- Consistent structure
- Clear organization
- Future replication for Novel #2

---

## 📁 FILES IN THIS DIRECTORY

### Current Config Files:
- `DRAFT_MODES.json` - Writing mode presets (Get It Down, Make It Good, Make It Shine)
- `settings.json` - Cursor settings for Walk This Way
- `prompts.json` - 11 JSON prompts for writing transformations

### Future Config Files:
- Additional COMPASS configuration files as system evolves

---

## 🎯 PURPOSE

This directory keeps all JSON config files organized in one place, making it:
- Easy to find configuration files
- Simple to replicate for new novels
- Clear what files control COMPASS behavior
- Consistent with `.cursor/rules/` organization pattern

---

**Note:** This is a custom COMPASS organization structure, not a standard Cursor directory.
