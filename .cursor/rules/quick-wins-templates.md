## 🧠 CHAIN OF THOUGHT TEMPLATES

### Simple Thinking
```
<thinking>
- What does [character] want?
- What's the subtext?
- What are the consequences?
</thinking>

[Your request]
```

### Detailed Thinking (Major Decisions)
```
<thinking>
Step 1: Character motivations
- [Character] wants: []
- [Character] wants: []
- Conflict: []

Step 2: Emotional subtext
- What's really being said beneath the words?
- What are they NOT saying?

Step 3: Power dynamics
- Who has the upper hand?
- How does this shift during the scene?

Step 4: Thematic implications
- How does this serve the "loss of innocence" theme?
- What does it reveal about class divisions?

Step 5: Narrative consequences
- What does this scene set up?
- How does it affect future chapters?
</thinking>

Now write the scene with this understanding.
```

### Plot Decision Thinking
```
Before deciding [decision], think through:
<thinking>
- What are [character]'s core values?
- What does the theme require?
- What are the narrative consequences?
- What would readers expect?
</thinking>

What should happen and why?
```

### Character Turning Point
```
Before writing [character]'s decision to [action], think through:
<thinking>
- What has [character] learned by this point?
- What are their competing motivations?
- How does this serve their character arc?
- What does it reveal about [theme]?
</thinking>

Write the decision scene.
```

### Complex Scene Revision
```
Before revising [scene], think through:
<thinking>
- What's the emotional core of this scene?
- What's working and what's not?
- What would make it more powerful?
- How does it connect to earlier scenes?
</thinking>

Now revise with these insights.
```

### Structural Problem
```
Before fixing [problem] in [chapter], think through:
<thinking>
- What's causing the problem?
- Where should tension build?
- What information needs to be revealed?
- How does this chapter serve the overall structure?
</thinking>

Provide specific fixes.
```

## 🎯 QUICK REFERENCE

### When to Use Which Template:

**For Scene Rewrites:**
→ XML Tags (Basic or Detailed Scene Rewrite)

**For Major Plot Decisions:**
→ Chain of Thought (Plot Decision Thinking)

**For Character Consistency:**
→ Few-Shot Examples (Character Voice Example)

**For Structural Analysis:**
→ Role Prompting (Developmental Editor) + Chain of Thought

**For Style Emulation:**
→ XML Tags (Style Emulation) + Few-Shot Examples

**For Quick Edits:**
→ XML Tags (Basic Scene Rewrite)

**For Complex Revisions:**
→ Power Combo 1 or 4 (All techniques)
