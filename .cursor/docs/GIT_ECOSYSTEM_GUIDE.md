## 📚 WHAT IS .GIT?

### **.git Folder**
**Location:** Hidden folder in your project root  
**What it is:** Local version control database  
**What it stores:** History of all changes (commits)

**Think of it as:** Your project's time machine - remembers every change

## 🔐 GIT vs GITHUB

### **Git (Local)**
- ✅ Lives on your Mac (`.git/` folder)
- ✅ Tracks changes locally
- ✅ No internet needed
- ✅ You control it

### **GitHub (Cloud)**
- ✅ Lives on internet (cloud backup)
- ✅ Syncs your `.git/` to cloud
- ✅ Backup & collaboration
- ✅ Access from anywhere

**Think:** Git = your local time machine, GitHub = cloud backup

## 📍 WHERE DOES GIT LIVE?

### **On Your Mac:**
- `.git/` folder in project root (hidden)
- All history stored here
- Works offline

### **On GitHub (Cloud):**
- Backup of your `.git/` folder
- Syncs when you `git push`
- Accessible from anywhere

### **In GitKraken/GitLens:**
- Visual interface to `.git/` folder
- Same data, different view
- Easier to understand

## 🎯 GIT CONCEPTS (Simple)

### **Commit = Save Point**
- Like saving a game
- Each commit = snapshot of project
- Can go back to any commit

### **Branch = Alternate Timeline**
- Draft_1 branch = one version
- Draft_2 branch = different version
- Can switch between branches

### **Merge = Combine Changes**
- Take changes from Draft_2
- Add to Draft_1
