# CURSOR CONFIGURATION EXAMPLES

## 🎯 **.cursorconfig FILE EXAMPLE**

### **File Name**: `.cursorconfig`
### **Location**: Same folder as your other files (root of your project)
### **Purpose**: Advanced Cursor configuration for novel writing

```
# Cursor Configuration for Novel Writing
# This file tells Cursor how to behave with your writing project

# AI Behavior Settings
ai.model = "claude-3.5-sonnet"
ai.temperature = 0.7
ai.max_tokens = 4000

# File Associations
file.associations = {
    "*.md" = "markdown",
    "*.txt" = "text",
    "*.draft" = "draft"
}

# Writing-Specific Settings
writing.mode = "novel"
writing.genre = "thriller"
writing.style = "stephen-king"

# AI Prompts for Writing
ai.prompts = {
    "character" = "Analyze this character like Stephen King would - focus on psychological depth, hidden fears, and realistic motivations",
    "dialogue" = "Make this dialogue sound natural and character-specific, with subtext and tension",
    "description" = "Add atmospheric details and sensory information to make this scene more immersive",
    "plot" = "Identify plot holes and suggest ways to increase tension and suspense"
}

# Beta Features
beta.realtime_suggestions = true
beta.multifile_context = true
beta.style_consistency = true
```

### **Location**: Same folder as your other files

## **STEPHEN KING-STYLE PROMPTS**

### **1. Character Development Prompt**
```
PROMPT: "Analyze this character like Stephen King would - focus on psychological depth, hidden fears, and realistic motivations"

USAGE: Select any character description or dialogue, then ask me to use this prompt.

EXAMPLE: "Use the character development prompt on this dialogue: 'I don't know what you're talking about,' Sarah said, avoiding eye contact."

RESULT: I'll analyze the character's psychology, hidden fears, and motivations in Stephen King's style.
```

### **2. Atmospheric Description Prompt**
```
PROMPT: "Add atmospheric details and sensory information to make this scene more immersive, like Stephen King's descriptive style"

USAGE: Select any scene description, then ask me to use this prompt.

EXAMPLE: "Use the atmospheric prompt on this scene: The old house stood silent in the storm."

RESULT: I'll add sensory details, atmospheric tension, and immersive descriptions.
```

### **3. Dialogue Enhancement Prompt**
```
PROMPT: "Make this dialogue sound natural and character-specific, with subtext and tension, like Stephen King's dialogue"

USAGE: Select any dialogue, then ask me to use this prompt.

EXAMPLE: "Use the dialogue prompt on this conversation between two characters."

RESULT: I'll make the dialogue more natural, add subtext, and increase tension.
```

### **4. Plot Tension Prompt**
```
PROMPT: "Identify plot holes and suggest ways to increase tension and suspense, like Stephen King's plotting techniques"

USAGE: Select any plot section, then ask me to use this prompt.

EXAMPLE: "Use the plot tension prompt on this chapter outline."

RESULT: I'll identify issues and suggest ways to increase tension and suspense.
```

## 🚀 **HOW TO USE CUSTOM PROMPTS**

### **Step 1: Create the Prompt File**
1. **Create** a new file called `custom_prompts.md`
2. **Copy** the prompts above into the file
3. **Save** the file in your project folder

### **Step 2: Use the Prompts**
1. **Select** text in your writing
2. **Ask me**: "Use the [prompt name] prompt on this text"
3. **I'll apply** the Stephen King-style analysis

### **Step 3: Customize Prompts**
1. **Modify** the prompts to match your writing style
2. **Add** new prompts for specific needs
3. **Save** your customized version
