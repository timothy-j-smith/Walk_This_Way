# CURSOR FOR NOVEL WRITING - COMPLETE REFERENCE GUIDE

## 🎯 QUICK START CHECKLIST
□ Open Cursor and log into your Pro+ account
□ Create .md files for each chapter
□ Use descriptive filenames (e.g., "Chapter_01_The_Beginning.md")
□ Select text and right-click for AI writing options
□ Use Cmd+K for inline AI editing
□ Use right panel for general writing questions

## 🚀 KEYBOARD SHORTCUTS FOR WRITING
- **Cmd+K** (Mac) / **Ctrl+K** (Windows): Inline AI editing
- **Cmd+L** (Mac) / **Ctrl+L** (Windows): Composer mode for larger changes
- **Cmd+I** (Mac) / **Ctrl+I** (Windows): Inline chat about selected code/text
- **Cmd+P** (Mac) / **Ctrl+P** (Windows): Print current file
- **Right-click**: Context menu with AI writing options

## 🎯 PROFESSIONAL WRITING TIPS
- Keep chapters in separate .md files for better AI context
- Use descriptive filenames for easy navigation
- Create character profiles in separate files
- Maintain a master outline to track story structure
- Use the right panel for broader story questions
- Use the middle panel for focused editing with Cmd+K

## 🚨 TROUBLESHOOTING
If AI features aren't working:
- Check if you're logged into your Pro+ account
- Verify keyboard shortcuts in Preferences
- Try right-clicking on selected text
- Make sure you're using .md files for chapters
