- **Searchable** - Easy to find specific information

## 🚀 **SESSION MANAGEMENT STRATEGY**

### **What Works:**
- **Specific, focused questions** - "How can I improve this dialogue?"
- **Clear context** - Provide material and ask for specific help
- **Technical guidance** - Grammar, structure, clarity improvements
- **Process support** - Workflow, organization, planning
- **Short sessions** - 30-45 minutes max
- **One topic per session** - Don't try to do everything

### **What Doesn't Work:**
- **Vague requests** - "Make this better" without specifics
- **Quality judgments** - "Is this good writing?" (inconsistent)
- **Creative direction** - "What should happen next?" (unreliable)
- **Long sessions** - Quality degrades over time
- **Multiple topics** - Confuses focus

### **Effective Prompts:**
- **"Help me improve the pacing in this paragraph"**
- **"Make this dialogue sound more natural"**
- **"Fix any grammar or clarity issues"**
- **"Suggest ways to strengthen this character's voice"**
