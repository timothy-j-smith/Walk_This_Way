## 💡 **ESSENTIAL COMMANDS**

### **Daily Writing Commands:**
- **Cmd+K**: Inline AI editing
- **Cmd+L**: Open Claude chat
- **Cmd+I**: Inline chat about selected text
- **Cmd+P**: Quick file open
- **Cmd+F**: Find in current file
- **Cmd+Shift+F**: Find in all files

### **File Management:**
- **Cmd+N**: New file
- **Cmd+Shift+N**: New folder
- **Cmd+S**: Save current file
- **Cmd+W**: Close current tab
- **Cmd+B**: Toggle sidebar
- **Cmd+\**: Split editor view

### **Advanced Commands:**
- **Cmd+Shift+L**: Add more context to chat
- **Cmd+I**: Composer mode for multi-file edits
- **Cmd+Z**: Undo
- **Cmd+Shift+Z**: Redo
- **Cmd+Tab**: Switch between open files

## 🎨 **AI WRITING TECHNIQUES**

### **Effective Prompts:**
- "Help me improve the pacing in this paragraph"
- "Make this dialogue sound more natural"
- "Fix any grammar or clarity issues"
- "Suggest ways to strengthen this character's voice"
- "Add more sensory details to this scene"
- "Increase the tension in this chapter"

### **What Works:**
- **Specific, focused questions** - Clear objectives
- **Clear context** - Provide material and ask for specific help
- **Technical guidance** - Grammar, structure, clarity improvements
- **Process support** - Workflow, organization, planning
- **Short sessions** - 30-45 minutes max
- **One topic per session** - Don't try to do everything

### **What Doesn't Work:**
- **Vague requests** - "Make this better" without specifics
- **Quality judgments** - "Is this good writing?" (inconsistent)
- **Creative direction** - "What should happen next?" (unreliable)
- **Long sessions** - Quality degrades over time
- **Multiple topics** - Confuses focus

## 🔧 **CONFIGURATION FILES**

### **.cursorconfig Example:**
```
# Cursor Configuration for Novel Writing
ai.model = "claude-3.5-sonnet"
ai.temperature = 0.7
ai.max_tokens = 4000

file.associations = {
    "*.md" = "markdown",
    "*.txt" = "text",
    "*.draft" = "draft"
}

writing.mode = "novel"
writing.genre = "thriller"
writing.style = "stephen-king"

ai.prompts = {
    "character" = "Analyze this character like Stephen King would - focus on psychological depth, hidden fears, and realistic motivations",
    "dialogue" = "Make this dialogue sound natural and character-specific, with subtext and tension",
    "description" = "Add atmospheric details and sensory information to make this scene more immersive",
    "plot" = "Identify plot holes and suggest ways to increase tension and suspense"
}
```

## 🎯 **SUCCESS CRITERIA**

### **What Makes a Productive Session:**
- **Clear objectives** - Know what you want to accomplish
- **Specific requests** - Technical help, not creative feedback
- **Focused work** - One aspect at a time
- **Time limits** - 30-45 minutes max
- **Regular breaks** - Fresh sessions, not long ones

### **What to Avoid:**
- **Creative feedback** - Quality assessment
- **Story development** - Character arcs, plot structure
- **Theme evaluation** - What works/doesn't work
- **Long sessions** - Quality degrades over time
- **Vague requests** - Unclear objectives
