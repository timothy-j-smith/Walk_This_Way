# SMARTWRITE USER GUIDE
**For Authors Using COMPASS**

---

## 🎯 WHAT IS SMARTWRITE?

SmartWrite is our **Smart Rewrites System** that enhances your prose using:
- **Liberty Levels** (Conservative/Moderate/High/Blue Sky)
- **Voice DNA** (Character voice consistency)
- **Subtext Reinforcement** (Thematic elements)
- **Comparison Views** (Side-by-side options)

**No code required!** Just talk to me (HANK) in chat.

---

## 🚀 HOW TO USE (3 SIMPLE METHODS)

### **Method 1: Simple Chat (Easiest!)**

Just tell me:

```
"SmartWrite Chapter 6, Moderate liberty"
"SmartWrite Chapter 11, Conservative"
"SmartWrite Chapters 4-6, High liberty"
```

**That's it!** I'll:
1. Read the chapter(s)
2. Identify key passages
3. Create enhancement options
4. Save everything to `SmartWrite/Results/`

---

### **Method 2: Specific Passages**

Tell me exactly what you want:

```
"SmartWrite Chapter 6, just the opening breakfast scene, Moderate"
"SmartWrite Chapter 11, passages 1-3, Conservative"
"SmartWrite this highlighted section, High liberty"
```

---

### **Method 3: Request Template (Optional)**

If you want to be very specific, use the template in `SmartWrite/Requests/REQUEST_TEMPLATE.md`

**But honestly, Method 1 is easiest!**

## 📊 HOW I SELECT PASSAGES

**When you say "SmartWrite Chapter X":**

I automatically identify:
- Opening scenes (first impressions)
- Emotional beats (conflict, revelation)
- Character voice moments (dialogue, internal monologue)
- Thematic moments (class divide, friendship, music)
- Transitions (scene changes, time shifts)

**You can override:** Just tell me which passages you want!

---

## 📁 WHERE FILES GO

**All SmartWrite results are in:** `SmartWrite/Results/`

**Organization:**
- Single chapter: `2025-11-29_Chapter_06_Jackies_World/`
- Multiple chapters: `2025-11-29_Chapters_04-06/`
- Partial chapter: `2025-11-29_Chapter_06_Passages_1-3/`

**Each folder contains:**
- `Enhancement_Report.md` (all options)
- `Selected_Options.md` (your choices)
- `Iterations/` (if you re-run)

