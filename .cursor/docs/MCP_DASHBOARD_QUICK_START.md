## 🚀 SUPER SIMPLE - JUST 2 COMMANDS

### **Step 1: Open Terminal, run this:**
```bash
cd /tmp/mcp-dashboard/backend && python3 server.py
```
**Leave this running!** (You'll see "Running on http://127.0.0.1:5002")

### **Step 2: Open NEW Terminal window, run this:**
```bash
cd /tmp/mcp-dashboard/frontend && npm install && npm start
```
**This will open your browser automatically!** 🎉
