# TAG EXPLORER EXPLANATION
**Date:** January 10, 2026

---

## WHAT IS TAG EXPLORER?

**Tag Explorer** shows all tags used in your files. Tags are markers you can use to organize and find content.

**In Cursor's File Explorer:**
- Shows up in the sidebar
- Lists all tags found in your project
- Click a tag to see all files that use it

---

## HOW TAGS WORK

### **Common Tag Formats:**
- `#tag` - Hashtag format (common in markdown)
- `@tag` - At-sign format (common in some systems)
- `tag:` - Prefix format

### **Example Uses:**
- `#TODO` - Mark tasks to do
- `#COMPASS` - Mark COMPASS-related content
- `#important` - Mark important notes
- `@character` - Mark character-related content
- `#review` - Mark items for review
