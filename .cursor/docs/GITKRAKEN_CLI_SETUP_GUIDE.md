# GitKraken CLI Setup Guide
**Date:** January 10, 2026

---

## STEP 1: DOWNLOAD GITKRAKEN CLI

**Download Link:** https://www.gitkraken.com/cli

**Installation:**
1. Visit the link above
2. Download for macOS
3. Follow installation instructions
4. **Free** with your GitKraken Pro subscription

---

## STEP 2: VERIFY INSTALLATION

After installing, verify it works:

```bash
gk --version
```

Should show GitKraken CLI version.

---

## STEP 3: AUTHENTICATE

```bash
gk auth login
```

This will:
- Open browser for authentication
- Link CLI to your GitKraken account
- Use your Pro subscription

---

## STEP 4: ADD TO MCP CONFIG

Once CLI is installed and authenticated, we'll add GitKraken MCP to your configuration.
