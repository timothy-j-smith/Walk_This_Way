## 📊 FILE EXPLORER PANEL ITEMS

### **Outline**
**What it is:** Hierarchical view of your document structure (headings, functions, classes, etc.)

**When to use:**
- Navigate long documents quickly
- See document structure at a glance
- Jump to specific sections

**Your status:** Shows structure of your current file

---

### **Timeline**
**What it is:** Git history view - shows file changes over time

**When to use:**
- See when files were modified
- View commit history
- Track changes to specific files

**Your status:** Shows Git commit history for your project

---

### **All Links**
**What it is:** Shows all markdown links (`[text](url)`) in your project

**When to use:**
- Find broken links
- See all cross-references
- Navigate between linked documents

**Your status:** Lists all markdown links in your project

---

### **Tag Explorer**
**What it is:** Shows all tags (like `#tag` or `@tag`) used in your files

**When to use:**
- Find files by tag
- See what tags you're using
- Organize content by tags

**Your status:** Shows all tags in your project (if any)

---

### **Notes**
**What it is:** Shows markdown notes or comments in your files

**When to use:**
- Find TODO comments
- See developer notes
- Track annotations

**Your status:** Lists notes/comments in your files
