# OTHER CHAT HISTORY ARCHIVE
**Purpose:** Store exported chat transcripts from other Cursor sessions (non-HANK)

---

## 📋 HOW TO USE

1. **After important sessions:** Export the transcript from Cursor
2. **Save it here** with a descriptive filename:
   - Format: `YYYY-MM-DD_Topic_Description.md`
   - Example: `2026-01-20_Character_Development_Session.md`

3. **Commit to Git** so it's backed up

---

## 📁 FILE NAMING CONVENTION

```
YYYY-MM-DD_Topic_Key_Details.md
```

---

## 🎯 WHAT TO EXPORT

- Important creative sessions
- Technical troubleshooting
- Research sessions
- Any session worth preserving

---

## 💡 NOTES

- This folder is for non-HANK chats
- HANK chats go in `../HANK/`
- Keep organized by date and topic
