## 🚀 INSTALLATION & USAGE

### **Install cursor-view:**

**Option 1: npm (if you have Node.js)**
```bash
npm install -g cursor-view
```

**Option 2: Clone from GitHub**
```bash
git clone https://github.com/saharmor/cursor-view.git
cd cursor-view
npm install
npm link
```

### **Use cursor-view:**

**Browse chat history:**
```bash
cursor-view browse
```

**Export all chats:**
```bash
cursor-view export --output ./chat_export/
```

**Search for specific chats:**
```bash
cursor-view search "DISCO"
cursor-view search "HANK"
cursor-view search "COMPASS"
```
