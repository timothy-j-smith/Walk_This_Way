## 📋 HOW TO USE

1. **After each major session:** Export the transcript from Cursor
2. **Save to correct folder:**
   - **HANK chats:** `HANK/` folder
   - **Other chats:** `Other/` folder
3. **Use descriptive filename:**
   - Format: `YYYY-MM-DD_Topic_Description.md`
   - Example: `2026-01-21_COMPASS_Writing_Guides_MCP.md`
4. **Commit to Git** so it's backed up
