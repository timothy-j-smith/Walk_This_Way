### **Option 2: cursor-chat-export (CLI Tool)** ⭐⭐⭐⭐

**Command-line tool - exports directly to markdown files**

**Steps:**
1. **Navigate to the tool:**
   ```bash
   cd /tmp/cursor-chat-export
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Discover your chats:**
   ```bash
   python cursor_chat_export.py discover
   ```

4. **Export all chats:**
   ```bash
   python cursor_chat_export.py export --output ~/Desktop/chat_export/
   ```

**This will:**
- ✅ Find all your chat databases
- ✅ Export each chat as a separate .md file
- ✅ Save to your specified directory
