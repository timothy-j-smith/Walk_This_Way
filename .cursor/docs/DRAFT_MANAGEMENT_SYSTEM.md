# DRAFT MANAGEMENT SYSTEM
**Date:** Saturday, November 29, 2025  
**Purpose:** Clear, simple system for managing multiple drafts

---

## 🎯 PRINCIPLES

1. **Clear Naming:** Draft_1, Draft_2, Draft_3 (simple, sequential)
2. **Keep Previous Draft:** Until new draft is complete
3. **Archive When Done:** Move old draft to Archive when new one is complete
4. **Self-Explanatory:** Clear even after a week away
5. **No Confusion:** Only active drafts visible, old drafts archived

---

## 📁 PROPOSED STRUCTURE

```
Walk This Way/
├── Draft_1/                    ← CURRENT: First complete draft (34 chapters)
│   ├── Act_I/
│   ├── Act_II/
│   └── Act_III/
│
├── Draft_2/                   ← FUTURE: Second draft (when you start rewriting)
│   ├── Act_I/
│   ├── Act_II/
│   └── Act_III/
│
├── Archive/
│   └── Completed_Drafts/      ← OLD: Drafts moved here when new one is complete
│       └── Draft_1/           ← (Moved here when Draft_2 is complete)
│
└── ...
```

---

## 🔄 WORKFLOW

### **Starting Draft 2:**
1. Create `Draft_2/` folder
2. Keep `Draft_1/` visible (for reference)
3. Work in `Draft_2/` (rewriting chapters)

### **While Working on Draft 2:**
- ✅ `Draft_1/` = Reference (keep visible)
- ✅ `Draft_2/` = Active work (your current draft)
- ✅ Can reference Draft_1 chapters while writing Draft_2

### **When Draft 2 is Complete:**
1. Move `Draft_1/` → `Archive/Completed_Drafts/Draft_1/`
2. `Draft_2/` becomes your reference draft
3. Ready to start `Draft_3/` if needed

---

## 📋 NAMING CONVENTIONS

### **Option A: Simple (Recommended)**
```
Draft_1/
Draft_2/
Draft_3/
```
**Pros:** Simple, clear, sequential  
**Best for:** Most writers

### **Option B: Descriptive**
```
Novel_Draft_1/
Novel_Draft_2/
Novel_Draft_3/
```
**Pros:** More descriptive  
**Cons:** Longer names

### **Option C: With Status**
```
Draft_1_Complete/
Draft_2_In_Progress/
```
**Pros:** Shows status  
**Cons:** Need to rename when status changes

## ✅ RECOMMENDED SYSTEM

### **Structure:**
```
Walk This Way/
├── Draft_1/              ← First complete draft (34 chapters)
├── Draft_2/              ← Second draft (when you start)
└── Archive/
    └── Completed_Drafts/ ← Old drafts (when new one is complete)
```

### **Rules:**
1. **Only 2 drafts visible at once** (current + previous for reference)
2. **When new draft is complete:** Archive the old one
3. **Clear naming:** Draft_1, Draft_2, Draft_3
4. **Self-explanatory:** Even after a week away, you know what's what
