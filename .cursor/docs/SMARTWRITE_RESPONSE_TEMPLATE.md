# SMARTWRITE RESPONSE TEMPLATE
**For Systematic Documentation**

---

## STANDARD RESPONSE FORMAT

**Every SmartWrite response should follow this structure:**

```markdown
# SMARTWRITE ENHANCEMENT — [Chapter Number] "[Chapter Title]"
**Date:** [YYYY-MM-DD]  
**Requested By:** [Author Name]  
**Liberty Level:** [Conservative / Moderate / High / Blue Sky]  
**Mode:** [Nice / Neutral / Professional]  
**Scope:** [Full Chapter / Specific Passages / Multiple Chapters]

---

## REQUEST SUMMARY

**Original Request:**
[Quote the exact request or reference the request file]

**Passages Selected:**
- [List of passages analyzed]

**Focus Areas:**
- [Voice DNA consistency / Subtext reinforcement / Purple prose removal / etc.]

---

## ANALYSIS

[Analysis section - same as current]

---

## ENHANCEMENTS

[Enhancement options - same as current]

---

## RESULTS

[Results section - same as current]

---

## NEXT STEPS

[Next steps - same as current]
```

---

## BENEFITS

**Consistent Format:**
- Easy to scan and compare across chapters
- Systematic documentation
- Clear request tracking
- Better reflection on changes

**First Few Lines Always Show:**
- Date
- Chapter
- Liberty Level
- Scope
- Request summary

---

**This ensures every SmartWrite response is both a working document AND systematic documentation!**
