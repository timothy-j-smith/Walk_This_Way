# FIRST DRAFTS DIRECTORY

**Purpose:** Store AI-generated first drafts from scene outlines

---

## WORKFLOW

1. **Generate** first draft from outline
2. **Save** here with date and scene identifier
3. **Refine** the draft (add your voice)
4. **Move** refined version to chapter file
5. **Enhance** with Smart Rewrites if needed

---

## FILE NAMING

- `Chapter_XX_Scene_YY_YYYY-MM-DD.md` - Original generated draft
- `Chapter_XX_Scene_YY_REFINED_YYYY-MM-DD.md` - After your edits
- `Chapter_XX_Scene_YY_FINAL_YYYY-MM-DD.md` - After Smart Rewrites

---

## STATUS

- 🟢 **Generated** - AI created first draft
- 🟡 **Refining** - You're editing it
- 🔵 **Refined** - Your version ready
- 🟣 **Enhanced** - After Smart Rewrites
- ✅ **Complete** - In final chapter
