# CURSOR WRITING SETUP GUIDE
*Your Complete Guide to Making Cursor Work Perfectly for Novel Writing*

## 🎯 QUICK START CHECKLIST

### ✅ 1. STABLE INTERFACE SETUP
**Make your layout permanent and predictable:**

- **Sidebar:** Press `Cmd+B` to toggle (keep it visible for file navigation)
- **Bottom Panel:** Press `Cmd+J` to toggle (keep it closed unless needed)
- **File Explorer:** Press `Cmd+Shift+E` to focus on your files
- **Search:** Press `Cmd+Shift+F` to search across all files

**Menu Access:** 
- Press `Cmd+Shift+P` then type what you want
- Common commands: "View: Toggle sidebar", "View: Toggle word wrap"

### ✅ 2. WRITING-OPTIMIZED SETTINGS
**Your workspace is already configured with:**
- ✅ Word wrap ON (no more toggling!)
- ✅ Auto-save every second
- ✅ Spell checker OFF (no more 4408 errors!)
- ✅ Format on save OFF (preserves your writing style)

### ✅ 3. NAVIGATION SHORTCUTS
**Essential keyboard shortcuts for writing:**

- `Cmd+P` = Quick file open (type filename to jump to it)
- `Cmd+Shift+P` = Command palette (access everything)
- `Cmd+B` = Toggle sidebar
- `Cmd+J` = Toggle bottom panel
- `Cmd+Shift+E` = Focus file explorer
- `Cmd+F` = Find in current file
- `Cmd+Shift+F` = Find across all files
- `Cmd+G` = Find next occurrence
- `Cmd+Shift+G` = Find previous occurrence

### ✅ 4. COMPOSER EXPLAINED
**What is Composer?**
- It's an advanced AI chat panel for complex tasks
- **How to access:** Press `Cmd+I` or click the purple "C" icon in sidebar
- **When to use:** For complex writing tasks, story analysis, character development
- **When NOT to use:** Simple questions (use regular chat instead)

**Composer vs Regular Chat:**
- **Regular Chat** (what we're using now): Quick questions, editing help
- **Composer**: Complex tasks like "Analyze my character arcs" or "Help restructure Chapter 5"

### ✅ 5. MENU VISIBILITY
**To see menus and know where you are:**

1. **View Menu:** Always visible at top - shows current layout options
2. **Status Bar:** Bottom of screen shows file info, line numbers, etc.
3. **Breadcrumbs:** Top of editor shows file path
4. **Activity Bar:** Left sidebar icons show what's active

### ✅ 6. AUTOCORRECT SETTINGS
**Configure smart autocorrect (not too aggressive):**

- **Settings:** `Cmd+,` to open settings
- **Search for:** "suggest" or "autocomplete"
- **Adjust:** Suggestion delay to 500ms (gives you time to type)
- **Turn off:** IntelliSense for markdown files (too distracting)

### ✅ 7. FILE ORGANIZATION
**Keep your writing organized:**

- **Use folders:** Ch_01/, Ch_02/, etc.
- **Naming convention:** Ch_01_Working.txt, Ch_01_Draft.txt
- **Quick access:** `Cmd+P` then type "ch_01" to jump to Chapter 1

## 🚨 TROUBLESHOOTING

### Problem: Interface keeps changing
**Solution:** Use the keyboard shortcuts above to reset to your preferred layout

### Problem: Can't find menus
**Solution:** Press `Cmd+Shift+P` - this is your universal menu

### Problem: Files won't open (iCloud sync issues)
**Solution:** Check iCloud settings, ensure "Optimize Mac Storage" is OFF

### Problem: Spelling errors everywhere
**Solution:** Reopen workspace (double-click .code-workspace file)

## 🎯 WRITING WORKFLOW

### Daily Writing Routine:
1. **Open workspace:** Double-click `Walk_This_Way.code-workspace`
2. **Navigate to chapter:** `Cmd+P` → type chapter name
3. **Start writing:** Word wrap is ON, auto-save is ON
4. **Use AI help:** Regular chat for quick questions, Composer for complex tasks

### File Management:
- **Working files:** Ch_XX_Working.txt (your current draft)
- **Backups:** Ch_XX_Archive/ (previous versions)
- **Documentation:** Keep in Documentation/ folder

## 💡 PRO TIPS

1. **Always use the workspace file** - it keeps your settings consistent
2. **Save frequently** - auto-save helps but manual saves are safer
3. **Use search** - `Cmd+Shift+F` to find character names, plot points
4. **Keep it simple** - don't overcomplicate with extensions you don't need
