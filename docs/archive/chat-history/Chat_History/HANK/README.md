# HANK CHAT HISTORY ARCHIVE
**Purpose:** Store exported chat transcripts from sessions with HANK (Super Agent)

---

## 📋 HOW TO USE

1. **After each major session with HANK:** Export the transcript from Cursor
2. **Save it here** with a descriptive filename:
   - Format: `YYYY-MM-DD_Topic_Description.md`
   - Example: `2026-01-21_COMPASS_Writing_Guides_MCP.md`

3. **Commit to Git** so it's backed up

---

## 📁 FILE NAMING CONVENTION

```
YYYY-MM-DD_Topic_Key_Details.md
```

**Examples:**
- `2026-01-21_COMPASS_Writing_Guides_MCP.md`
- `2026-01-10_COMPASS_Encyclopedia_Creation.md`
- `2025-11-29_Reorganization_Session.md`

---

## 🎯 WHAT TO EXPORT

- Major sessions (new features, breakthroughs)
- Technical troubleshooting sessions
- Creative collaboration sessions
- DISCO moments
- Any session with important decisions or learnings

---

## 💡 NOTES

- This folder is specifically for HANK chat transcripts
- Other chats go in `../Other/`
- Past sessions may not be recoverable, but we've captured important parts in `HANK_DNA.md` and session summaries
- The `state.vscdb` backup contains the complete chat history for restoration after clean install
