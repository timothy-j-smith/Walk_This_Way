# Fix Terminal Stuck Issue
**Date:** January 10, 2026

---

## PROBLEM

You're stuck in a `dquote>` prompt because a command wasn't completed properly.

---

## SOLUTION: ESCAPE THE STUCK PROMPT

**In your terminal, press:**
```
Ctrl + C
```

This will cancel the incomplete command and return you to a normal prompt.
