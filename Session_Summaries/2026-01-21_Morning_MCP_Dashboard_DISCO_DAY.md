## 🔧 TECHNICAL DETAILS

### **Backend (Python Flask):**
- Parses markdown files to extract MCP data
- Serves REST API endpoints:
  - `/api/mcps` - Get all MCPs (with filters)
  - `/api/mcp/<mcp_id>` - Get specific MCP
  - `/api/stats` - Get statistics
  - `/api/apis` - Get API requirements
- Runs on `http://localhost:5002`

### **Frontend (React):**
- Modern React application
- Dark theme with professional styling
- Expandable MCP cards
- Search and filter functionality
- Responsive design
- Runs on `http://localhost:3000`

### **Data Parsing:**
- Extracts MCP data from:
  - `MCP_ARSENAL_RANKED_PRIORITY.md`
  - `REVOLUTIONARY_FICTION_WRITING_MCP_SYSTEM_COMPLETE.md`
- Reads active MCPs from `.cursor/config/mcp.json`
- Categorizes: Active, Archived, Excluded
