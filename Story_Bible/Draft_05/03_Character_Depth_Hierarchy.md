# Character Depth Hierarchy — Walk This Way

**Purpose:** Who gets how much interiority, what we withhold, and how each person carries the theme *inheritance is renunciation.*

**Depth tiers:**

| Tier | Access | Rule |
| ---- | ------ | ---- |
| **1 — Spine** | Full scenes, dialogue, arc | Nick, Jackie |
| **2 — Bridge** | First-person frame + selective past | Maxanne |
| **3 — Witness** | ~4 hinge chapters interiority | Patty |
| **4 — Parents** | Bricks only: object + one withheld fact | Grace, Dan, Richard, Eileen |
| **5 — Mirrors** | One revelation scene + object arc | Wentworth, (Tom Andrews) |
| **6 — Orbit** | Voice, one object, no backstory dump | Bandmates, Carl, Lenny, Kowalski |
