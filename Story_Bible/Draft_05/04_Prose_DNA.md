# Prose DNA — Walk This Way

Locked craft document for Draft_05. When in doubt: **Architecture → Brick → Scalpel → Hose.**

## Core method (COMPASS)

| Phase | Job |
| ----- | --- |
| **Architecture** | What must this chapter *do*? One spine job; split if two rooms fight. |
| **Brick** | Scene, object, body, dialogue — meaning shown, not argued. |
| **Scalpel** | Cut thesis, duplicate metaphor, frame spoilers, inventory lists. |
| **Hose** | Restore rhythm, breath, sinew — pressure on both sides of the cut. |

**Failure mode (Ch 13 lesson):** Scalpel without hose → **telegram prose** (stacked subject-verb beats: *She saw X. He went inside.*). Reads like police report, not King/Lehane/Ondaatje.

**Guardrail:** Every brick/scalpel pass ends with **read-aloud**. If three lines sound like a column, merge before save.

## Narration contract

### Maxanne frame (2009 booth)

- **POV:** First person, present tense.  
- **Authorized:** Her own WBCN story (Ch 11); objects she holds (cassette, bourbon, headphones); compression, fragment, withholding.  
- **Forbidden:** Glossing the meaning of brick chapters the reader just saw or is about to see. No pre-game final score (Ch 9 problem).  
- **Voice:** Radio warmth — specific objects, earned pauses, Boston cadence without dialect zoo. One hose line per scene max; never three sentences that paraphrase the same guilt.

### Brick chapters (1974–1979)

- **POV:** Third person, past tense, **witnessed** — camera in the room, not in everyone's head.  
- **Exception:** Patty hinge chapters (~4) — interiority earned; still no thesis paragraphs.  
- **Omniscience problem:** Maxanne cannot know Eileen alone with nine canvases (Ch 20). Fix at frame level in pass 2 — license on last page, or tighten to what could be known. Do not cut the scene; fix the contract.

## Register

**Target:** Flowing third-person with **earned** pauses — not staccato columns, not purple hose.

- **Long sentence** loads image or list.  
- **Short sentence** fires once per beat (*Forty feet.* / *They sat.*).  
- **Fragments** OK for **catalog** (cafeteria geography, clique texture). Not for plot recap or emotional summary.

## Not-naming discipline

Theme travels by **recurring objects and motions**, never announced:

| Motif | Instances |
| ----- | --------- |
| **Closed lids** | Toolbox, piano fallboard, casket, cassette case |
| **Hands** | Marsh octave pinky (**4-beat cap:** Ch 3, 7, 10, 26), Eileen's brush hand, Dan/Nick calluses (**2-word cap novel-wide**), Grace on storm door |

**Callus budget:** **2 max** novel-wide (earned tactile lines). Zero spent in Ch 1–11.

## Professor lenses (principles, not imitation)

| Lens | Use for |
| ---- | ------- |
| **Ondaatje** | Gap, image, motion; replace one theme sentence with one object |
| **Lehane** | Class as physical fact; diner/PTA rooms; wit that carries danger |
| **Dickey** | Body-first pivot scenes (bridge, shop, stage) |
| **King** | Working-class dialogue comedy; cut the last explanatory paragraph |
| **Robinson** | Patience — truth stated once; theology of renunciation without church |

## Show vs tell — highest-leverage rules

1. Trust the object. Cut the sentence after the object that explains the object.  
2. One crowd body > choral summary (*lunch lady frozen with tongs* > "every parent knew").  
3. Frame states **facts** of complicity; reader renders verdict (Ch 27).  
4. Parents: **brick via object**, never biography.summary paragraph.

## Frame object budgets (author lock — 6/2026)

### Bourbon — not a chapter tic

Maxanne is more than the pour. Bourbon is **complicity fuel**, not booth wallpaper.

| Rule | Detail |
| ---- | ------ |
| **Novel budget** | **2–3 meaningful bourbon beats** across the **entire 2009 frame** (41 chapters), each in a **different register** (smell in the cup / thumb-measured pour / empty cup / last swallow / gone). |
| **Forbidden** | Default transitions: *I take a finger of bourbon*, *warmth spreads through my chest* every frame chapter. |
| **Arc** | Bottle **diminishes** across the four-hour shift; **runs dry** before or during the final tape play (Act III–V). Empty cup = earned beat. |
| **Pass 2** | Ch 1 currently stacks **three** bourbon lines in the opening — consolidate to **1–2**. Ch 16 opening pour is fine; **do not repeat** in every Act II frame. Ch 9 model: **cold coffee** as alternate fuel. |

### Cassette — sacred object, scarce full passes

The **May '79 unauthorized tape** is the loaded gun. Treat like **callus budget**: full sensory only when the chapter **job** requires it.

| Sense | Use |
| ----- | --- |
| **Weight** | Case in palm; plastic that doesn't get lighter |
| **Smell** | Magnetic oxide, old plastic, faint smoke — **never taste** |
| **Look** | Faded ballpoint label; Maxell; latch |

**Full sensory chapters (target ~3–4 novel-wide):** Ch 1 establish; complicity chapter (~Ch 27–30); play-on-air (~Ch 38–40). **Light touch elsewhere:** label legible, pick up / put down, *not tonight* — OK (Ch 9, 16).

**Not the same object:** Ch 6 TDK bootlegs (friendship brick); Ch 11 Panasonic (discovery) — different tapes, different jobs.
