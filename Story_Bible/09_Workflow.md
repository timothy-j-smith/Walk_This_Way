## Writing phases

### 1. Structure (Architecture)

What must this chapter **accomplish**? One job. Outline lives in `02_Chapter_Outline.md`.

**Return here rarely** during edit pass — only if a chapter’s job is wrong (e.g. re-funeral when the reader already mourned).

### 2. Scene draft (Brick)

Write so we’re **in the room** — dialogue, objects, bodies. Third-person past for 1974–1979; Maxanne frame = first-person present in the booth.

**Draft_05 → Draft_06:** Scene draft is **done** for all 41 chapters. We are not re-architecting.

### 3. Review (Diagnose)

Read aloud (or listen). Mark what works (`!`), what’s off (`cut`), questions (`?`).

Audio is the best test for repetition and frame voice.

### 4. Line edit (Scalpel + Hose — one motion)

Cut dead prose, explanation, repeated motifs; **replace in the same pass** with cleaner lines. Not two separate steps.

### 5. Review again (Diagnose)

Read aloud until the chapter clears.

### 6. Loop or exit

- Still wrong at **sentence** level → line edit again  
- Still wrong at **scene** level → back to Structure (rare)  
- Chapter clears → next chapter  
- All 41 clear → **Final polish** (consistency, copyedit, grep)

```
Structure → Scene draft → Review → Line edit → Review → … → Final polish
                ↑                              |
                └──────── Structure (rare) ────┘
```

## Edit pass (Draft_06) — session rhythm

1. Open `07_Pass_2_Focus.md` for chapter status and locks  
2. Open `Draft_06/Chapter_XX_*.txt`  
3. **Canon skim** — if the edit might touch **family, place, or timeline**, read the character’s row in `03_Character_Depth_Hierarchy.md` + grep `PARKING_LOT.md` first (see **Canon guardrails** below)  
4. **Review** — read aloud  
5. **Line edit** — cut + replace  
6. **Review** — read aloud again  
7. Update `08_Phrase_Ledger.md` if a phrase locks or retires  
8. Update `06_Chapter_Expanded.md` only if the chapter’s on-page summary changed materially  
9. **Compare** — `tmp/Chapter_XX_*_BEFORE.txt` vs `Draft_06` (Compare Selected); never trust line numbers across files after ACT headers

## Canon guardrails (avoid invented backstory)

**What went wrong (Ch 6 bike):** A valid note (“don’t mirror Patty’s Dump reclaim”) was fixed by **inventing** an older brother and Lowell — neither in bible. Repetition fixes must not create new facts.

### Before adding ANY new biographical detail

Grep or read first:

- `03_Character_Depth_Hierarchy.md` — who exists, withheld facts, **Never** list  
- `PARKING_LOT.md` — author locks (Grace NW not Wellesley, Concord not Maple, no Nick brother, etc.)  
- `05_Sudbury_Geography_Brief.md` — if place names appear  
- Prior chapters in `Draft_06/` — is it already on the page?

### Rules of thumb

| Do | Don’t |
| --- | --- |
| **Subtract** — cut the repeating image (Dump bike, chain gag) | **Invent** relatives, towns, jobs, or history to replace a cut |
| **Repoint** to canon already on page (pawn shop Ch 4, Dutton Road, Dan’s garage) | Add “older brother,” “cousin in Lowell,” etc. without author sign-off |
| **Ask** when the fix needs a fact not in bible | Improvise under time pressure |
| **Flag** in chat: “Canon check: no sibling listed for Nick — using X instead” | Assume working-class = hand-me-down from random relative |
| **Cut shrug tautologies** (*The house was just the house*; *Not X. Y.*) | Restate the room after the object already showed it |

### Fix patterns that are safe

- **Mirror problem** → remove the echo, keep the simpler version already implied  
- **Wrong address** → swap to locked geography (Concord Road, Dutton Road)  
- **Purple / thesis** → cut or replace with object in hand  
- **New object** → one glance, tie to existing character (Dan’s hacksaw, job-site paint) — **no new people**

### Your role (author)

- Read-aloud is still the best canon alarm — if a line makes you ask “wait, who?” stop and flag it  
- “Canon check this paragraph” before moving on is always fair  
- Compare view: unchanged blocks should align; if content surprises you, grep the bible
