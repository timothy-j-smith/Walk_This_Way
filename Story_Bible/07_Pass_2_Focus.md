## Pass 2 thesis (why we're here)

**The story is built.** The Greek tragedy engine survived Draft_05. We did **not** veer into Blueprint viral resurrection. What failed the audio test is **execution**: repetition, frame chapters that **report history** instead of **host a live broadcast**, and motif inventory where **glance** would carry the thread.

**True subject (unchanged):** *Inheritance is renunciation, not gift.* Loss of innocence in four layers — personal, class/town, institutional, cultural — ending in **virtue-driven choice → loss → confession → catharsis without rescue.**

**Pass 2 job:** Make the prose **cleaner, crisper, poetic under pressure** — co-written with the professor lenses — so the tragedy **lands in the ear**, not only on the page.

*Recurring by design ≠ same sentence every time. Three tiers:*

| Tier | Rule |
| ---- | ---- |
| **Full brick** | One complete sensory pass per object arc |
| **Glance** | One word or motion — reader already knows |
| **Echo (cut)** | Same inventory reshuffled — **delete** |
