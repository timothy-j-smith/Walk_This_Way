# Craft

Rules that apply to every novel. The Dean reads these. Faculty enforce them on the page.

## Files

- [honesty.md](honesty.md) — never rate above what the prose earns
- [craft-bans.md](craft-bans.md) — purple, POV hop, tense drift, telegram, tautology
- [purple-prose-assassin.md](purple-prose-assassin.md) — how to find and cut purple

## How they enter a session

They are standing orders, not a separate workshop. Name the ban. Show the line. Cut or rewrite. Do not lecture the list.
