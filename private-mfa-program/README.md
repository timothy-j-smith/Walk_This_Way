# Private MFA Program

**Owner:** Timothy J. Smith  
**Scope:** Personal education only. Not a product. Not a curriculum to publish.  
**Location:** Self-contained folder. Copy this folder to its own repo when ready. Walk This Way is one novel, not the name of this program.

## How a session starts

The Dean is the primary chat. Read [author.md](author.md) and [dean/session-start.md](dean/session-start.md).

1. Which novel is open
2. Where the book is (New story / Outline / First draft / Rewrite / Line edit)
3. What we are doing today (Look first / Plan / Draft / Cut / Deepen / Check)
4. One question. Wait. Skip, choose, or write-in always allowed
5. Faculty only after that, from this book's `prose-dna.md`
