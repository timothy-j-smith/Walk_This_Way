# Novel Pack

Copy this folder into a novel. Fill what you can. Leave what you cannot. Same shape every book.

Walk This Way is one novel. It is not the name of this pack.

## Copy

1. Copy everything in this folder into the novel's root (or into `novels/[book-slug]/` if the book lives inside this program)
2. Rename titles inside each file
3. Write `prose-dna.md` before long drafting
4. Open `project-hub.md` every session

## Files

- [project-hub.md](project-hub.md) — session door
- [story-bible.md](story-bible.md) — logline, themes, world, timeline
- [synopsis.md](synopsis.md) — one to two pages
- [acts.md](acts.md) — three acts
- [chapter-outline.md](chapter-outline.md) — titles only
- [chapter-expanded.md](chapter-expanded.md) — three to four sentences per chapter
- [character-hierarchy.md](character-hierarchy.md) — tiers
- [prose-dna.md](prose-dna.md) — voice, faculty, sentence rules
- [vault.md](vault.md) — cuts for this book only
- [collaboration.md](collaboration.md) — how we co-write
- [chapter-review.md](chapter-review.md) — one question at a time after a draft
- [working-manuscript.md](working-manuscript.md) — assembled read-through
- [chapters/](chapters/README.md) — source of truth for prose
- [chat-summaries/](chat-summaries/README.md) — every working session
- [series/](series/README.md) — later-book seeds, not this vault
- [idea-capture.md](idea-capture.md) — new-story questions, one at a time

## Authority

1. `chapters/` prose
2. `vault.md` (what was cut)
3. story-bible and character-hierarchy facts
4. This MFA program
5. Lab MCPs

## Naming

Lowercase. Dashes. Chapter files: `ch01-short-title.txt` or `.md` — pick one per book and stay.
