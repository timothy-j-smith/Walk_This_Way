# Chat Summaries

Every working session. Not only when someone remembers to ask.

**Naming:**

- One per day: `YYYY-MM-DD.md`
- Same day, second file: `YYYY-MM-DD-2.md`

## What to capture

Use this shape (from the Father of Mine session that worked):

1. **Headline** — one paragraph: what the book or the writer found today
2. **Buried gems** — story, character, collaboration notes that did not make bible, outline, or chapter
3. **Decisions locked**
4. **Open / waiting on Timothy**
5. **Next session** — one named job
6. Faculty who sat
7. Where we stopped

## Trigger

End of session the Dean writes one. Timothy can also say *provide a chat summary*.

MFA-wide student file is `private-mfa-program/author.md` — do not rebuild that here.
