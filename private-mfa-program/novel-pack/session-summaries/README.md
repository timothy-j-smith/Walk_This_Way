# Session summaries

Walk This Way stores these in the novel root: `Session_Summaries/`.

New novels using this pack: copy this folder as `session-summaries/` inside that novel.

Write one only when Timothy says the sitting is over (going to bed, leaving for work, “create a session summary”). Not after every chat turn.

**Naming (Walk This Way):** `YYYY-MM-DD_HHMM_PDT_Short_Title.md` (use `PST` in winter).

## What to capture

1. **Headline** — one paragraph: what the book or the writer found today
2. **Buried gems** — story, character, collaboration notes that did not make bible, outline, or chapter
3. **Decisions locked**
4. **Open / waiting on Timothy**
5. **Next session** — one named job
6. Faculty who sat
7. Where we stopped

MFA-wide student file is `private-mfa-program/author.md` — do not rebuild that here.
