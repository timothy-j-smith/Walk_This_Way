# Chapters

Source of truth for prose.

**Naming:** `ch01-short-title.md` or `.txt` — one style per book.

## Workflow

1. Draft the chapter in its file
2. Timothy edits and approves
3. Confirmed prose syncs to `../working-manuscript.md`
4. Cuts go to `../vault.md`

Do not silently overwrite. New pass = sibling file until he says replace.
