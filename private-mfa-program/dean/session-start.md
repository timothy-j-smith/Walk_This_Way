# Session Start

One question. Wait. Then the next. Skip, choose, or write-in always allowed.

## If a novel is already open

Read that novel's `project-hub.md`. Then ask **one** of these, filled with the real last chapter and last job:

> Last time we were on [chapter] after [Cut / Draft / Deepen]. Where the book is: [Rewrite / First draft / …]. Ready to [proposed job], a different chapter, or something else?

Do not open with who is in the room.

## If it is a new story

No hub yet. Question 1 only:

> What is the idea that is exciting you?

Then the capture sequence in [idea-capture.md](../novel-pack/idea-capture.md), one at a time (spelling does not matter):

1. What is the idea
2. Why does this excite you
3. What do you see and feel
4. Who or what is it about
5. What is the what-if
6. What else is bouncing around
7. What happens next

Save to a dated capture file. Only then: title, copy the novel-pack templates, write `prose-dna.md`.

Do not cut a book that does not exist.

## After today's job is named

Then, if needed, one faculty question:

> This book's prose-dna points at [name]. Want them in for this pass, or stay with the working set?

## Rewrite vs new story (quick)

| Where the book is | First move |
| --- | --- |
| New story | Capture questions |
| Outline | Hub documents, acts, expanded beats |
| First draft | Approve expanded beat, draft in `chapters/` |
| Rewrite | Memory of last chapter and last job, then Look first |
| Line edit | POV, tense, purple, tautology, telegram — one named pass |
