```
   ↓

   - Reads: Previous commits (character consistency history)
   - Reads: Branch context (draft-2 branch)

   ↓
5. github MCP: Query repository metadata
   - Checks: Related issues (character consistency issues)
   - Checks: Commit patterns (consistency check history)
   ↓
6. compass-writing-guides MCP: Apply COMPASS rules
   - Checks: Writing guide rules
   - Validates: COMPASS standards
   ↓
7. Sequential Thinking MCP: Synthesize all findings
   - Combines: Filesystem data + Git context + COMPASS rules
   - Concludes: Comprehensive consistency report
   ↓
8. Report to You: Before commit
   "✅ Character: Matches Story Bible
    ❌ Timeline: Dan's death date inconsistency (1976 vs 1977)
    ✅ Prose: No purple language found
    ⚠️ Plot: Chapter 12 reference needs verification
    Found 2 issues. Should I help fix before commit?"
```

**All MCPs Working Together:**
- **Filesystem MCP** = Reads your files
