### **Brother 2: The Fiction Specialist**
**Analysis:** What's fiction-specific vs. what's universal?

**Fiction-Specific Considerations:**

1. **Continuity vs. Parallelization:**
   - Technical chapters can be independent
   - **Fiction chapters MUST maintain narrative flow**
   - **Recommendation:** Use Background Agents for SCENES within chapters, not entire chapters
   - **Example:** Generate 5 action scenes in parallel, but review for continuity

2. **Character Voice Consistency:**
   - Technical: Consistent terminology
   - **Fiction: Each character needs unique voice**
   - **Recommendation:** Create character-specific DNA profiles (like we have for Carolina, Jazz, Hank)
   - **Enhancement:** Add character voice "temperature" controls

3. **Emotional Arc vs. Information Density:**
   - Technical: Information density varies by audience
   - **Fiction: Emotional intensity varies by scene**
   - **Recommendation:** Add "emotional temperature" parameter
   - **Example:** High emotional temp for climactic scenes, low for transitions

4. **Narrative Pacing:**
   - Technical: Doesn't need pacing control
   - **Fiction: Pacing is critical**
   - **Recommendation:** Add pacing control parameters
   - **Example:** Fast-paced action (high temp, short sentences) vs. contemplative (low temp, longer)

5. **Dialogue vs. Prose:**
   - Technical: Mostly prose
   - **Fiction: Dialogue needs different controls**
   - **Recommendation:** Separate dialogue generation parameters
   - **Example:** Dialogue temp: 0.8 (natural speech), Prose temp: 0.6 (controlled)

**Verdict:** **Core concepts work, but need fiction-specific adaptations.**
