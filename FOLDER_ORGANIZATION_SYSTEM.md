## 📋 FOLDER DESCRIPTIONS

### ⭐ `Active_Draft_2/` - CURRENT WORK

**Purpose**: Files you're actively using for Draft 2 work

**What Goes Here**:
- Current blueprints (V2 is latest)
- Current style guide
- Any active planning documents

**Rules**:
- ✅ **ONLY CURRENT FILES** (delete old versions)
- ✅ **Print these** for review
- ✅ **Update as needed** (new versions replace old)
- ❌ **NO DUPLICATES** (one version only)

**When to Clean**:
- When a file is superseded → Delete old, keep new
- When Draft 2 is complete → Move to `Draft_2/` or archive

---

### 📋 `Session_Summaries/` - HISTORICAL RECORDS

**Purpose**: Daily session documentation (never delete)

**Naming Convention**: `YYYY-MM-DD_Time_Session_Title.md`

**Examples**:
- `2026-01-13_Evening_Draft_2_Planning_Marathon.md`
- `2026-01-15_Morning_File_Organization_Cleanup.md`

**Rules**:
- ✅ **Keep all summaries** (historical record)
- ✅ **Use for reference** when context is lost
- ✅ **Chronological order** (date in filename)

---

**Purpose**: Original Draft 1 chapters (read-only reference)

**Rules**:
- ✅ **Reference only** (don't edit)
- ✅ **Use when rewriting** Draft 2 chapters
- ❌ **Don't delete** (source material)

## 🎯 WORKFLOW RULES

### For Active Files

1. **Check `Active_Draft_2/` FIRST** - These are your current files
2. **Print for review** - Tactile review with handwritten notes
3. **Use `((comments))` system** - Digital annotations
4. **Delete old versions** - Don't keep duplicates
5. **Update as needed** - New versions replace old

### For Session Summaries

1. **Create at end of session** - Document what happened
2. **Use proper naming** - `YYYY-MM-DD_Time_Title.md`
3. **Never delete** - Historical record
4. **Reference when needed** - Context preservation

### For File Cleanup

1. **When file is superseded**:
   - Delete old version
   - Keep only current version
   - Update `Active_Draft_2/` folder

2. **When work is complete**:
   - Move to appropriate folder (`Draft_2/` or archive)
   - Remove from `Active_Draft_2/`

3. **Regular maintenance**:
   - Check `Active_Draft_2/` for duplicates
   - Remove obsolete files
   - Keep only CURRENT files

---

## 🚨 AVOID THESE MISTAKES

❌ **Keeping multiple versions** of same file (causes confusion)  
❌ **Files in root folder** that should be in `Active_Draft_2/`  
❌ **Outdated files** mixed with current files  
❌ **No clear "current" file** (which one do I use?)  
❌ **Session summaries** in wrong location or wrong naming  

---

## ✅ SUCCESS CRITERIA

**You should always know**:
- ✅ Which files are CURRENT (check `Active_Draft_2/`)
- ✅ Which files are REFERENCE (check `Draft_1/`, `Story_Bible/`)
- ✅ Which files are HISTORICAL (check `Session_Summaries/`)
- ✅ No duplicates or confusion
- ✅ Clear workflow (print → review → update)
