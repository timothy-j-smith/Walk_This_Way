HOW TO PRINT (you do this)

Cursor preview is for reading only. Command-P in Cursor is search, not print.

Get the file into Preview (the Mac PDF app), then print:

1. In the left file list, open Writing_System_Map
2. Right-click FRESH_START.pdf  (or START_HERE.pdf)
3. Choose Reveal in Finder
4. Double-click the PDF — a new window opens (Preview)
5. Click that Preview window once
6. Top of the Mac screen: File → Print
   (Command-P works here only after Preview is in front)
