## TROUBLESHOOTING

### "XML tags don't seem to help"
→ Make sure you're using them for complex requests, not simple ones  
→ Try combining with Chain of Thought

### "Pinning doesn't save time"
→ Make sure you're pinning the right files (Story Bible, Directives, Current Chapter)  
→ Unpin when switching focus

### "Chain of Thought takes too long"
→ Use for major decisions only, not every request  
→ Combine with XML tags for efficiency

### "Few-Shot examples don't match style"
→ Make sure your Good example is actually your best writing  
→ Create multiple example pairs for different techniques

### "Role prompting gives same feedback"
→ Try different roles on the same question  
→ Combine with other techniques
