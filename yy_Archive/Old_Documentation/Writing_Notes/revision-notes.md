## Prose Improvement Checklist

Use this for each chapter revision:

### First Pass (Structure):
- [ ] Does chapter serve the story arc?
- [ ] Is POV consistent?
- [ ] Does it start and end strongly?
- [ ] Is pacing appropriate for content?

### Second Pass (Scene-Level):
- [ ] Does each scene have purpose?
- [ ] Are transitions smooth?
- [ ] Is dialogue authentic to character?
- [ ] Are actions clear and motivated?

### Third Pass (Line-Level):
- [ ] Replace "was/were" with active verbs
- [ ] Show emotions through physical details
- [ ] Vary sentence structure and rhythm
- [ ] Cut unnecessary words
- [ ] Strengthen verb choices
- [ ] Add sensory details where thin

### Fourth Pass (Polish):
- [ ] Read aloud - does it flow?
- [ ] Check for echoes (repeated words)
- [ ] Verify punctuation
- [ ] Consistency checks (names, details)
