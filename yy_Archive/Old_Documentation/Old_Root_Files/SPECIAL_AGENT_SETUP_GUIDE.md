# SPECIAL AGENT SETUP GUIDE

## 🎯 OVERVIEW
This guide explains how to use the 3 specialized agents for systematic novel refinement through 3 focused passes.

## 📋 THE 3 SPECIALIZED AGENTS

### **AGENT 1: CHARACTER_DEPTH_COACH**
**Role:** Character Development and Story Authenticity Expert
**Mission:** Elevate character psychology, emotional resonance, and story depth
**Files:** CHARACTER_DEPTH_COACH.md, Agent.md, Approved_Chapters/, Story_Bible/

### **AGENT 2: PROSE_POLISH_EXPERT**
**Role:** Prose Polish and Voice Consistency Specialist  
**Mission:** Elevate prose quality to 8/10+ level while maintaining voice consistency
**Files:** PROSE_POLISH_EXPERT.md, Agent.md, Approved_Chapters/, COMPREHENSIVE_ANALYSIS

### **AGENT 3: STRUCTURAL_PERFECTION_SPECIALIST**
**Role:** Final Polish and Structural Perfection Expert
**Mission:** Perfect story structure, pacing, and thematic coherence
**Files:** STRUCTURAL_PERFECTION_SPECIALIST.md, Agent.md, Approved_Chapters/, COMPREHENSIVE_ANALYSIS

## 🚀 HOW TO INITIATE A SPECIAL AGENT

### **STEP 1: START NEW CHAT**
- Open new Cursor chat conversation
- This ensures clean context and focused attention

### **STEP 2: REFERENCE AGENT FILES**
**Opening Message Template:**
```
I'm working with [AGENT_NAME]. Please reference [AGENT_FILE].md and Agent.md. 
I'm ready to begin [PASS_NUMBER] - [FOCUS_AREA] of my 34-chapter novel 'Walk This Way.'
```

**Examples:**
- "I'm working with CHARACTER_DEPTH_COACH. Please reference CHARACTER_DEPTH_COACH.md and Agent.md. I'm ready to begin Pass 1 - Character Depth analysis of my 34-chapter novel 'Walk This Way.'"
- "I'm working with PROSE_POLISH_EXPERT. Please reference PROSE_POLISH_EXPERT.md and Agent.md. I'm ready to begin Pass 2 - Prose Polish of my 34-chapter novel 'Walk This Way.'"
- "I'm working with STRUCTURAL_PERFECTION_SPECIALIST. Please reference STRUCTURAL_PERFECTION_SPECIALIST.md and Agent.md. I'm ready to begin Pass 3 - Structural Perfection of my 34-chapter novel 'Walk This Way.'"

### **STEP 3: AGENT BOUNDARIES**
Each agent is bound to their job description and Agent.md. If you ask them to do something outside their role, they will suggest alternatives that maintain your creative vision.

## 🔄 THE 3-PASS SYSTEM

### **PASS 1: CHARACTER & STORY DEPTH**
**Agent:** CHARACTER_DEPTH_COACH
**Focus:** 
- Character psychology and authenticity
- Emotional resonance
- Story gaps and missing pieces
- Character voice consistency
**Deliverable:** Deeper, more authentic characters

### **PASS 2: PROSE & VOICE REFINEMENT**
**Agent:** PROSE_POLISH_EXPERT
**Focus:**
- Stephen King influence optimization
- Word choice and repetition
- Show vs. tell improvements
- Voice consistency (Maxanne vs. third-person)
**Deliverable:** Polished, professional prose

### **PASS 3: STRUCTURAL PERFECTION**
**Agent:** STRUCTURAL_PERFECTION_SPECIALIST
**Focus:**
- Pacing and flow
- Theme consistency
- Plot hole fixes
- Final inconsistencies
**Deliverable:** Publication-ready manuscript

## 📁 FILES AVAILABLE TO AGENTS

### **ALWAYS VISIBLE:**
- ✅ `Approved_Chapters/` (34 polished chapters)
- ✅ `Agent.md` (creative vision)
- ✅ `Story_Bible/` (character & timeline details)
- ✅ `Documentation/` (continuity tracker)
- ✅ `Research/COMPREHENSIVE_NOVEL_ANALYSIS_AND_WRITING_COACH_GUIDE.md` (synopsis)

### **HIDDEN BY .cursorignore:**
- ❌ `Extra_Files/` (draft materials)
- ❌ `Rough_Draft_Assembly/` (working files)
- ❌ `Archive_Pre_Reorg/` (old versions)
- ❌ `Planning/` (planning documents)
- ❌ `Writing_Notes/` (personal notes)

## 💡 BENEFITS OF THIS SYSTEM

### **FOR YOU:**
- **Progressive improvement** - Each pass elevates quality
- **Focused expertise** - Each agent has specific skills
- **Manageable process** - You control the pace
- **Quality assurance** - You review each pass

### **FOR AGENTS:**
- **Clean context** - Fresh chat for each agent
- **Clear boundaries** - Know exactly what to do
- **Focused expertise** - No confusion about responsibilities
- **Consistent quality** - Reference Agent.md for vision

## 🎯 IMPLEMENTATION WORKFLOW

1. **Create Agent 1** for Pass 1
2. **Work through all 34 chapters** with CHARACTER_DEPTH_COACH
3. **Create Agent 2** for Pass 2
4. **Work through refined chapters** with PROSE_POLISH_EXPERT
5. **Create Agent 3** for Pass 3
6. **Final polish pass** with STRUCTURAL_PERFECTION_SPECIALIST

## 🔧 ALTERNATIVE METHODS

### **METHOD 1: FRESH SESSIONS (RECOMMENDED)**
Start new chat for each agent - clean context, focused attention

### **METHOD 2: .cursorignore CONTROL**
Hide agents you're not using by adding to .cursorignore

### **METHOD 3: DIRECT REFERENCE**
In same chat, reference specific agent: "Please act as CHARACTER_DEPTH_COACH"

## 📋 TEMPLATE FOR FUTURE NOVELS

This system can be replicated for any novel:
1. Create 3 specialized agent files
2. Set up .cursorignore for clean presentation
3. Follow 3-pass refinement system
4. Use fresh sessions for each agent
