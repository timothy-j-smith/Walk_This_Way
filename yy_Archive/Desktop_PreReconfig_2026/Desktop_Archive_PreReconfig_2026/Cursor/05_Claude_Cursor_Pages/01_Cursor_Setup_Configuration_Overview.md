## ⚙️ **CONFIGURATION FILES**

### **.cursorconfig File**
Located in your project root, this file controls Cursor's behavior for your specific project.

**Essential Settings:**
- AI model selection
- Temperature and token limits
- File type associations
- Custom prompts
- Beta feature toggles

### **File Associations**
Tells Cursor how to handle different file types:
- `.md` files → Markdown mode
- `.txt` files → Text mode
- `.draft` files → Draft mode
- Custom file types

### **Custom Prompts**
Reusable AI prompts for specific writing tasks:
- Character development
- Dialogue enhancement
- Plot analysis
- Style checking

## 📁 **FILE ORGANIZATION**

### **Recommended Structure:**
```
Novel_Project/
├── .cursorconfig          # Project configuration
├── Chapters/              # Chapter files
├── Planning/              # Story planning
├── Power_Moves/           # Writing tools
├── Research/              # Research notes
└── Publishing/            # Query letters, etc.
```

### **File Naming Conventions:**
- **Chapters**: `Chapter_01_The_Beginning.md`
- **Planning**: `Character_Profiles.md`
- **Tools**: `01-Master_Control.txt`
- **Research**: `Research_Notes.md`

## 🚨 **COMMON ISSUES**

### **Installation Problems:**
