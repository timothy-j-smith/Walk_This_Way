## A-0: ARCHITECTURE OVERVIEW

### WHAT ARCHITECTURE MEANS

Architecture is the **strategic blueprint** of your novel - the decisions you make BEFORE writing that determine everything that follows. Like an architect designing a building before construction begins, you're designing your story's foundation, structure, and purpose.

**Architecture answers:**
- WHY am I writing this story?
- WHAT story am I telling?
- WHO is this for?
- HOW will it be structured?
- WHEN/WHERE does it happen?
- WHAT THEMES will it explore?

**Architecture is NOT:**
- The actual writing (that's Creation)
- The polishing (that's Editing)
- The selling (that's Publishing)

**Architecture IS:**
- The vision
- The blueprint
- The foundation
- The strategy
- The map

### HOW TO USE THESE TOOLS

#### THE THREE PHASES OF ARCHITECTURE

**Phase 1: Discovery (Tools A1-A5)**
- Finding your story's core
- Understanding your why
- Mapping the big picture
- Making fundamental choices

**Phase 2: Design (Tools A6-A10)**
- Building character arcs
- Creating conflict layers
- Establishing voice/tone
- Planning pacing

**Phase 3: Detailed Planning (Tools A11-A15)**
- Market positioning
- Research needs
- Revision strategy
- Project management
- Failure prevention

#### WHEN TO USE ARCHITECTURE TOOLS

**BEFORE writing a new novel:**
- Work through A1-A15 in order
- Spend 1-2 weeks total
- Fill templates completely
- Make firm decisions

**DURING writing:**
- Reference when stuck
- Check decisions against A1 (Compass)
- Use A3 (Decision Tree) for choices
- Don't revise architecture mid-draft

**AFTER first draft:**
- Review all architecture
- Note what changed organically
- Decide what to honor
- Update for revision

## C-0: CREATION OVERVIEW

### CREATION VS EDITING MINDSET

#### THE FUNDAMENTAL DIFFERENCE

**CREATION MINDSET (Green Light)**
- Permission to be messy
- Quantity over quality
- Forward momentum only
- "Yes, and..." thinking
- Embrace imperfection
- Generate possibilities
- Follow tangents
- Trust the process
- Silence inner critic
- Write badly with joy

**EDITING MINDSET (Red Light)**
- Permission to be ruthless
- Quality over quantity
- Can move backward
- "No, but..." thinking
- Pursue perfection
- Eliminate excess
- Stay on track
- Question everything
- Engage critical faculty
- Fix problems systematically

#### THE SACRED SEPARATION

**Never Mix These Modes In Same Session:**

**Morning Creation Session:**
```
✓ Generate new material
✓ Follow inspiration
✓ Write forward only
✓ Accept all ideas
✓ Celebrate word count
✗ Don't read yesterday's work
✗ Don't fix typos
✗ Don't question plot
✗ Don't perfect sentences
```

**Afternoon Editing Session:**
```
✓ Fix existing material
✓ Question everything
✓ Cut ruthlessly
✓ Perfect sentences
✓ Improve quality
✗ Don't generate new scenes
✗ Don't add subplots
✗ Don't follow new ideas
✗ Don't increase word count
```

### CLAUDE PROMPT BASICS

#### THE ANATOMY OF A PERFECT PROMPT

**1. CONTEXT LOADING**
```
@[File-name.txt] ← Gives Claude background
"Using the character profile attached..."
```

**2. SPECIFIC REQUEST**
```
"Generate a 2000-word chapter that..."
NOT: "Write something good"
```

**3. CONSTRAINTS/PARAMETERS**
```
- POV: First person
- Tense: Past
- Tone: Noir/cynical
- Must include: [specific elements]
```

**4. QUALITY MARKERS**
```
"Include sensory details, internal monologue,
subtext in dialogue, and varying sentence lengths"
```

#### PROMPT FORMULAS THAT WORK

**Formula 1: The Expansion**
```
"Take this outline: [outline]
Expand into a [word count] scene with [requirements]"
```

**Formula 2: The Alternative**
```
"Here's version A: [text]
Generate version B with [different approach]"
```

**Formula 3: The Fix**
```
"This scene has problem X: [paste scene]

```

**Formula 4: The Style Match**

### QUICK PROMPT LIBRARY

#### FOR STARTING SCENES

**The Action Start:**
```
"Start in media res with [character] already doing [action].
No setup, no explanation. Reader learns through action."
```

**The Dialogue Start:**
```
"Open with dialogue that reveals conflict. No tags for
first three lines. Let tension build through words alone."
```

**The Sensory Start:**
```
"Begin with a specific sensory detail that's wrong/unusual.
Let the wrongness build unease before revealing why."
```

#### FOR DEVELOPING SCENES

**Add Subtext:**
```
"Characters say one thing but mean another. Add layers
where dialogue contradicts internal thoughts/body language."
```

**Increase Tension:**
```
"Add a ticking clock element. Someone needs to leave by X,
or something happens at Y time. Build pressure."
```

**Deepen Character:**
```
"Add internal monologue showing character's real feelings
contradicting their actions. Show their struggle."
```

#### FOR ENDING SCENES

**The Cliffhanger:**
```
"End mid-action or mid-revelation. Stop at the moment of
highest tension, not resolution."
```

**The Reversal:**
```
"End with information that reframes entire scene. What seemed
true wasn't. Reader must reconsider everything."
```

**The Question:**
```
"End with character (or reader) asking a question that
demands the next chapter be read for the answer."
```

#### FOR SPECIFIC PROBLEMS

**Boring Dialogue:**
```
"Add conflict to every exchange. Characters want different
things. No one agrees. Interruptions and subtext throughout."
```

**Flat Description:**
```
"Make setting active, not static. Weather changes, lights
flicker, sounds intrude. Environment affects action."
```

**Weak Emotion:**
```
"Show emotion through physical sensation and action, not
statements. Body betrays what words hide."
```

## C-1: BLUEPRINT MASTER

### GENERATION GOAL
Creates the foundational document that ensures every generated chapter serves your story's core purpose. This blueprint keeps AI-assisted generation aligned with your vision, preventing drift and maintaining consistency across all created content.

### PROMPT TEMPLATE

```
@C01-BLUEPRINT-MASTER.txt

You are helping me write a [GENRE] novel with these parameters:

PREMISE: [One sentence setup]
THEME: [What it's really about]
TONE: [Dark/Light/Mixed]
PACING: [Fast/Moderate/Literary]
STYLE: [Sparse/Rich/Balanced]

THREE-ACT STRUCTURE:
- Act 1 (25%): [What happens]
- Act 2A (25%): [What happens]  
- Act 2B (25%): [What happens]
- Act 3 (25%): [What happens]

STAKES:
- Personal: [What character loses]
- Professional: [Career stakes]
- Global: [World consequences]

Keep all generated content aligned with these parameters.
Never violate the tone or theme. Every scene must serve
the premise and advance toward the established ending.
```

### INSTRUCTIONS: STEP BY STEP

**Step 1: Complete Architecture First**
- Fill A1-A5 completely
- Make all major decisions
- Lock in your vision
- Don't proceed until certain

**Step 2: Transfer to Blueprint**
- Copy key decisions
- Simplify language
- Focus on constraints
- Make rules clear

**Step 3: Create Master File**
- Save as C01-BLUEPRINT-MASTER.txt
- Reference in EVERY prompt
- Update if vision changes
- Keep under 500 words

**Step 4: Test with Sample**
- Generate one scene
- Check against blueprint
- Adjust parameters
- Refine until aligned

## E-0: EDITING OVERVIEW

### EDITING PHILOSOPHY

#### THE FOUR PILLARS OF EDITING

**1. RESPECT THE STORY**
- Serve the tale, not your ego
- Honor what works
- Fix what doesn't
- Know the difference

**2. RESPECT THE READER**
- Their time is precious
- Their intelligence is high
- Their patience is limited
- Their trust is earned

**3. RESPECT THE CRAFT**
- Language has rules
- Stories have structures
- Genres have conventions
- Excellence has standards

**4. RESPECT YOURSELF**
- Your voice matters
- Your vision is valid
- Your growth takes time
- Your effort deserves polish

#### THE EDITING MINDSET

**You Are A Surgeon:**
- Precise cuts
- Minimal damage
- Maximum impact
- Healing purpose

**You Are A Sculptor:**
- Remove excess
- Reveal essence
- Smooth rough edges
- Polish to shine

**You Are An Engineer:**
- Test every component
- Strengthen weak points
- Remove redundancy
- Optimize performance

### ORDER OF OPERATIONS

#### THE HIERARCHY OF EDITING (Big to Small)

```
LEVEL 1: STRUCTURAL EDITING (Weeks 1-2)
Does the story work?
├─ Beginning hooks?
├─ Middle holds?
├─ Ending satisfies?
├─ Causality clear?
└─ Fix these FIRST

↓

LEVEL 2: CHARACTER EDITING (Week 3)
Do the people work?
├─ Motivations clear?
├─ Arcs complete?
├─ Voices distinct?
├─ Relationships earned?
└─ Fix these SECOND

↓

LEVEL 3: SCENE EDITING (Week 4)
Do the moments work?
├─ Each scene necessary?
├─ Tension present?
├─ Dynamics vary?
├─ Transitions smooth?
└─ Fix these THIRD

↓

LEVEL 4: LINE EDITING (Week 5)
Do the sentences work?
├─ Voice consistent?
├─ Flow natural?
├─ Clarity achieved?
├─ Style polished?
└─ Fix these FOURTH

↓

LEVEL 5: COPY EDITING (Week 6)
Are mechanics correct?
├─ Grammar proper?
├─ Spelling correct?
├─ Punctuation right?
├─ Format consistent?
└─ Fix these LAST
```

**NEVER EDIT BACKWARDS** (Don't polish sentences you might cut)

### HOW TO APPLY: INSTRUCTIONS

**Step 1: Read Chapter Fresh (20 min)**
- Print if possible
- Read as reader, not writer
- Don't fix anything yet
- Mark problem spots only

**Step 2: Score Each Element (30 min)**
- Be brutally honest
- 5 = barely acceptable
- 7 = good enough
- 10 = exceptional
- No element below 5

**Step 3: Identify Weakest (5 min)**
- Circle lowest score
- This is fix priority
- Don't fix multiple
- Focus on biggest problem

**Step 4: Generate Fix (20 min)**
- Use appropriate prompt
- Target specific weakness
- Maintain strengths
- Don't break what works

**Step 5: Re-score (10 min)**

## SHEET 3: ESSENTIAL PROMPTS FOR CLAUDE

### UNIVERSAL PROMPT STARTERS

**For Analysis:**
```
"Analyze this chapter using [specific criteria].
Identify the three biggest weaknesses and explain why."
```

**For Generation:**
```
"Generate [specific length] of [specific type]
following these parameters: [list]. Include [elements]."
```

**For Revision:**
```
"Revise this [text] to fix [specific problem]
while maintaining [what's working]. Keep the same length."
```

**For Comparison:**
```
"Compare these two versions. Which better serves [goal]?
Explain the specific strengths of each."
```

### PROBLEM-SPECIFIC PROMPTS

**Fix Boring:**
```
"Add tension through: ticking clock, hidden agenda,
conflicting goals, or unexpected interruption."
```

**Fix Confusing:**
```
"Clarify: who's present, where we are, when this happens,
what's at stake, and why it matters."
```

**Fix Overwritten:**
```
"Cut 30% without losing meaning. Remove redundancy,
excessive description, and unnecessary dialogue."
```

**Fix Underwritten:**
```
"Add sensory details, internal monologue, and
physical reactions. Show the scene fully."
```

### STYLE PROMPTS

**Match Voice:**
```
@voice-sample.txt
"Rewrite this dialogue to match the voice profile.
Maintain meaning but adjust style, rhythm, vocabulary."
```

**Vary Pacing:**
```
"Vary sentence lengths for better rhythm.
Mix short punchy sentences with longer flowing ones."
```

**Show Don't Tell:**
```
"Convert all telling statements to showing through
action, dialogue, or sensory detail."
```
