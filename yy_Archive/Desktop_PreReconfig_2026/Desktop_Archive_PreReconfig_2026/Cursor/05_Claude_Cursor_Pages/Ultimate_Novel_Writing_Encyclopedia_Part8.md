## CHAPTER 37: ESSENTIAL PROMPTS LIBRARY

### UNIVERSAL PROMPT STARTERS

**For Analysis:**
```
"Analyze this chapter using [specific criteria].
Identify the three biggest weaknesses and explain why."
```

**For Generation:**
```
"Generate [specific length] of [specific type]
following these parameters: [list]. Include [elements]."
```

**For Revision:**
```
"Revise this [text] to fix [specific problem]
while maintaining [what's working]. Keep the same length."
```

**For Comparison:**
```
"Compare these two versions. Which better serves [goal]?
Explain the specific strengths of each."
```

### PROBLEM-SPECIFIC PROMPTS

**Fix Boring:**
```
"Add tension through: ticking clock, hidden agenda,
conflicting goals, or unexpected interruption."
```

**Fix Confusing:**
```
"Clarify: who's present, where we are, when this happens,
what's at stake, and why it matters."
```

**Fix Overwritten:**
```
"Cut 30% without losing meaning. Remove redundancy,
excessive description, and unnecessary dialogue."
```

**Fix Underwritten:**
```
"Add sensory details, internal monologue, and
physical reactions. Show the scene fully."
```

### STYLE PROMPTS

**Match Voice:**
```
@voice-sample.txt
"Rewrite this dialogue to match the voice profile.
Maintain meaning but adjust style, rhythm, vocabulary."
```

**Vary Pacing:**
```
"Vary sentence lengths for better rhythm.
Mix short punchy sentences with longer flowing ones."
```

**Show Don't Tell:**
```
"Convert all telling statements to showing through
action, dialogue, or sensory detail."
```

### CHARACTER DEVELOPMENT PROMPTS

**Character Analysis:**
```
"Analyze this character like Stephen King would - focus on psychological depth, hidden fears, and realistic motivations"
```

**Dialogue Enhancement:**
```
"Make this dialogue sound natural and character-specific, with subtext and tension"
```

**Character Consistency:**
```
"Check this text for voice consistency with the character profile provided"
```

**Emotional Depth:**
```
"Add internal monologue showing character's real feelings contradicting their actions. Show their struggle."
```

### PLOT DEVELOPMENT PROMPTS

**Plot Analysis:**
```
"Identify plot holes and suggest ways to increase tension and suspense"
```

**Scene Improvement:**
```
"Make this scene more engaging by adding conflict, character goals, obstacles, and sensory details"
```

**Pacing Control:**
```
"Speed up the pacing of this scene with shorter sentences, more action verbs, and a ticking clock element"
```

**Tension Building:**
```
"Add tension through: ticking clock, hidden agenda, conflicting goals, or unexpected interruption"
```

## CHAPTER 39: EMERGENCY PROTOCOLS

### WHEN STUCK ON STORY

**Emergency Protocol:**
```
1. Open Claude Max
2. Present specific problem
3. Explore multiple solutions
4. Choose best approach
5. Return to Cursor
6. Implement solution
```

**Common Stuck Points:**
- "I don't know what happens next"
- "This character doesn't make sense"
- "The plot feels forced"
- "I'm losing interest in my own story"
- "The middle is sagging"

**Quick Solutions:**
- Use Story Compass (A01)
- Apply Decision Tree (A03)
- Run Chapter Formula (E05)
- Check Story Gaps (E06)
- Use Power Prompts (E10)

### WHEN OVERWHELMED BY VERSIONS

**Version Rescue Protocol:**
```
1. Use Version Decision Matrix (E00)
2. Score objectively (6 criteria)
3. Choose base version
4. Harvest best elements
5. Merge systematically
6. Move forward
```

**Emergency Merge Rules:**
- Pick one version as base
- Add ONE best element from others
- Don't try to use everything
- Focus on moving forward
- Perfect is the enemy of done

### WHEN LOSING MOTIVATION

**Motivation Recovery Protocol:**
```
1. Check Master Control (E01)
2. Review progress made
3. Remember why you're writing
4. Set small, achievable goal
5. Focus on one thing
6. Celebrate small wins
```

**Quick Motivation Boosters:**
- Read your Story Compass
- Look at progress dashboard
- Remember your "why"
- Set tiny goal (100 words)
- Use your strongest tool
- Take a short break

### WHEN QUALITY FEELS LOW

**Quality Improvement Protocol:**
```
1. Use Chapter Formula (E05)
2. Identify specific problems
3. Apply targeted fixes
4. Check improvements
5. Focus on one element
6. Build confidence
```

**Quick Quality Fixes:**
- Fix weakest element first
- Use Power Prompts (E10)
- Apply Scene Dynamics (E08)
- Check Voice DNA (E09)
- Run Polish Passes (E13)

### WHEN SYSTEM FEELS COMPLEX

**Simplification Protocol:**
```
1. Use only Master Control (E01)
2. Pick ONE Power Move
3. Use it for one week
4. Add complexity only when needed
5. Focus on consistency over perfection
```

**Essential Tools Only:**
- Master Control (E01)
- Chapter Formula (E05)
- Power Prompts (E10)
- Daily Log (E04)
- Story Compass (A01)

### WHEN BURNING OUT

**Burnout Prevention Protocol:**
```
1. Check energy levels
2. Reduce daily goals
3. Take breaks
4. Focus on sustainability
5. Remember this is a marathon
6. Seek support if needed
```

**Recovery Actions:**
- Take a day off
- Read for inspiration
- Go for a walk
- Talk to other writers
- Remember your why
- Start small when ready
