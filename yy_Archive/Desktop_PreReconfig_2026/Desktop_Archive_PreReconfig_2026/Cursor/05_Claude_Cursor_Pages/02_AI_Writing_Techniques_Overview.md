## 🎨 **PROMPT ENGINEERING FUNDAMENTALS**

### **The Perfect Prompt Structure:**
1. **Context** - What you're working on
2. **Specific Request** - What you want the AI to do
3. **Constraints** - Any limitations or requirements
4. **Quality Markers** - What good output looks like

### **Example Perfect Prompt:**
```
Context: I'm writing a thriller novel about a journalist investigating murders.
Request: Help me improve this dialogue between the protagonist and a suspicious source.
Constraints: Keep it under 200 words, maintain tension, show character personality.
Quality: Natural speech, subtext, advancing plot, revealing character.
```

### **What Makes Prompts Effective:**
- **Specificity** - Clear, detailed requests
- **Context** - Relevant background information
- **Constraints** - Clear boundaries and requirements
- **Examples** - Show what you want
- **Iteration** - Refine based on results

## 🎭 **CHARACTER DEVELOPMENT WITH AI**

### **Character Analysis Prompts:**
- "Analyze this character's motivation and suggest improvements"
- "What would this character do in this situation?"
- "How can I make this character more sympathetic?"
- "What hidden depths could this character have?"

### **Character Voice Development:**
- "Make this dialogue sound more like [Character Name]"
- "Adjust this character's speech patterns to match their background"
- "Add internal thoughts that reveal this character's personality"
- "Show this character's emotional state through their actions"

### **Character Arc Assistance:**
- "How should this character change throughout the story?"
- "What internal conflict could drive this character's growth?"
- "What would be a satisfying character arc for this person?"
- "How can I show this character's transformation?"

## 💬 **DIALOGUE ENHANCEMENT**

### **Natural Dialogue Prompts:**
- "Make this dialogue sound more natural and conversational"
- "Add subtext to this conversation where characters say one thing but mean another"
- "Increase the tension in this dialogue exchange"
- "Make each character's voice more distinct"

### **Dialogue Function Prompts:**
- "Use this dialogue to reveal important plot information"
- "Make this conversation advance the relationship between these characters"
- "Add conflict to this dialogue where characters want different things"
- "Use this exchange to show character personality differences"

### **Dialogue Quality Prompts:**
- "Remove unnecessary dialogue tags and make this flow better"
- "Add physical actions to break up this long dialogue"
- "Make this dialogue more concise while keeping the meaning"
- "Add interruptions and hesitations to make this more realistic"

## 📖 **PLOT DEVELOPMENT ASSISTANCE**

### **Plot Structure Prompts:**
- "Help me structure this chapter with proper pacing"
- "What plot points should happen in this section?"
- "How can I increase tension in this scene?"
- "What obstacles could make this character's goal harder?"

### **Plot Problem Solving:**
- "I'm stuck on how to get my character from Point A to Point B"
- "This plot twist feels forced - how can I make it more natural?"
- "Help me foreshadow this later revelation"
- "What subplot could add depth to this story?"

### **Plot Consistency:**
- "Check this chapter for plot holes or inconsistencies"
- "Does this scene serve the overall story purpose?"
- "How does this event connect to earlier plot points?"
- "What consequences should this action have?"

## ✍️ **STYLE CONSISTENCY**

### **Voice Maintenance:**
- "Check this text for voice consistency with the rest of the novel"

- "Replace this exposition with a scene that demonstrates the same information"

## 🚨 **COMMON AI PROBLEMS**

### **Poor AI Responses:**
- **Vague prompts** - Be more specific
- **Lack of context** - Provide background
- **Unclear constraints** - Set clear boundaries
- **No examples** - Show what you want

### **Inconsistent Quality:**
- **Inconsistent prompts** - Use templates
- **Changing context** - Maintain consistency
- **Mixed instructions** - Be clear and focused
- **No feedback loop** - Refine based on results

### **AI Not Understanding:**
- **Complex requests** - Break into smaller parts
- **Unclear language** - Use simple, direct language
- **Missing context** - Provide relevant background
- **Conflicting instructions** - Be consistent
