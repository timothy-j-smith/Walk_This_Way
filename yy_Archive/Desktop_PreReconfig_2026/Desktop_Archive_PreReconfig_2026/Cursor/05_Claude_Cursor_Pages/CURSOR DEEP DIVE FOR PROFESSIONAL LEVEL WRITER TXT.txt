# ITERATIVE DEVELOPMENT SYSTEM

## ROUND 1: BASIC GENERATION (Skeleton)
PROMPT: "Generate Chapter [X] based on outline. Focus on getting plot points correct."
OUTPUT: Chapter-[X]-R1-skeleton.txt
TARGET: Plot complete, 70% of word count
TIME: 20 minutes

## ROUND 2: CHARACTER VOICE (Personality)
PROMPT: "@CHARACTER-DNA.txt Revise all dialogue and internal monologue to match character voices"
OUTPUT: Chapter-[X]-R2-voice.txt
TARGET: Distinct character voices
TIME: 15 minutes

## ROUND 3: SENSORY ENHANCEMENT (Atmosphere)
PROMPT: "Add sensory details: sight, sound, smell, touch, taste. Make setting vivid."
OUTPUT: Chapter-[X]-R3-sensory.txt
TARGET: Reader can visualize scene
TIME: 10 minutes

## ROUND 4: TENSION INJECTION (Page-turner)
PROMPT: "Add micro-tensions every 250 words. Vary sentence lengths for rhythm."
OUTPUT: Chapter-[X]-R4-tension.txt
TARGET: No flat sections
TIME: 10 minutes

## ROUND 5: HOOK OPTIMIZATION (Polish)
PROMPT: "Strengthen opening hook and closing cliffhanger. Maximum impact."
OUTPUT: Chapter-[X]-R5-hooks.txt
TARGET: Compelling start/end
TIME: 5 minutes

## ROUND 6: FINAL COHERENCE (Unity)
PROMPT: "Smooth all transitions. Ensure consistent POV and tense."
OUTPUT: Chapter-[X]-FINAL.txt
TARGET: Reads as unified whole
TIME: 10 minutes

TOTAL: 70 minutes per chapter
QUALITY: Escalates from 60% to 95%

MARKDOWN CHEATSHEET - The Fun Ones!
HEADERS (Hierarchy)

markdown
# H1 - Biggest Header (Book Title)
## H2 - Big Header (Chapter Title)
### H3 - Medium Header (Section)
#### H4 - Small Header (Subsection)
##### H5 - Smaller (Detail)
###### H6 - Smallest (Fine print)
TEXT FORMATTING

markdown
**Bold text** or __Bold text__
*Italic text* or _Italic text_
***Bold AND italic*** 
~~Strikethrough~~ (for deleted text)
`Code or highlight` (makes text stand out in gray box)
LISTS

markdown
Bullet Points:
- First item
- Second item
  - Nested item (2 spaces before dash)
    - Double nested (4 spaces)

Numbered Lists:
1. First item
2. Second item
   1. Nested (3 spaces)
   2. Another nested

Checkboxes (perfect for you!):
- [ ] Unchecked box
- [x] Checked box
LINKS & REFERENCES

markdown
[Link text](http://url.com)
[Link to another file](filename.txt)
@filename.txt (Cursor's special reference)
QUOTES & BLOCKS

markdown
> This is a blockquote (indented, gray)
> Good for examples or quotes
```This is a code block```
(Three backticks before and after)
Good for templates or prompts
HORIZONTAL LINES (Section Breaks)

markdown
--- (three dashes)
*** (three asterisks)
___ (three underscores)
