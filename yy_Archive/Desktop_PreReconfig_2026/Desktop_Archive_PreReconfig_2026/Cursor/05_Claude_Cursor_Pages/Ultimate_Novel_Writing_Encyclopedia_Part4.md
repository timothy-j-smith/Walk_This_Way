## CHAPTER 15: VERSION RESCUE & MASTER CONTROL

### E00: VERSION DECISION MATRIX - OBJECTIVE SCORING

When you have multiple versions of the same chapter, this tool provides objective criteria for choosing the best base version and identifying elements to harvest from others.

#### THE 6-POINT SCORING SYSTEM

**1. HOOK (First 50 words) - 10 points**
- Starts with action/question/intrigue
- No throat-clearing/weather/waking
- Immediate forward momentum
- Voice clear from first sentence
- Genre appropriate

**2. VOICE (Character Consistency) - 10 points**
- Character sounds authentic
- Dialogue matches personality
- Internal thoughts feel right
- Actions align with character
- Voice remains consistent

**3. PLOT (Story Advancement) - 10 points**
- Chapter serves story purpose
- Events follow logically
- Stakes are clear
- Conflict drives action
- Moves story forward

**4. PACING (Reader Engagement) - 10 points**
- Appropriate rhythm for content
- No boring sections
- Tension maintained
- Smooth transitions
- Page-turner quality

**5. EMOTION (Reader Connection) - 10 points**
- Emotional impact achieved
- Reader cares about outcome
- Stakes feel real
- Character growth shown
- Satisfying experience

**6. ENDING (Chapter Conclusion) - 10 points**
- Ends with question/revelation
- Compels next chapter
- Not artificial/forced
- Genuine story development
- Reader must continue

### E06: STORY GAPS - CAUSE-EFFECT AUDIT

#### GAP IDENTIFICATION CHECKLIST

**Timeline Jumps:**
- [ ] All events in logical sequence
- [ ] No unexplained time gaps
- [ ] Character movements make sense
- [ ] Cause-effect relationships clear
- [ ] No impossible simultaneity

**Character Development:**
- [ ] Motivations established clearly
- [ ] Character growth shown step-by-step
- [ ] Relationships develop naturally
- [ ] Backstory supports current behavior
- [ ] No personality inconsistencies

**Plot Logic:**
- [ ] Each event follows from previous
- [ ] No deus ex machina solutions
- [ ] Character actions have consequences
- [ ] Stakes escalate logically
- [ ] Resolution earned by story

**World Consistency:**
- [ ] Rules established and followed
- [ ] Technology works consistently
- [ ] Geography makes sense
- [ ] Social systems logical
- [ ] No contradictory information

**Missing Scenes:**
- [ ] All important events shown
- [ ] Character decisions explained
- [ ] Plot points developed fully
- [ ] Transitions smooth
- [ ] No jarring jumps

#### GAP FIXING PROTOCOL

**Step 1: Identify Gap Type**
- Timeline issue
- Character inconsistency
- Plot logic problem
- World-building error
- Missing scene

**Step 2: Determine Fix Method**
- Add bridging scene
- Revise existing scene
- Add explanation
- Change sequence
- Delete problematic element

**Step 3: Implement Fix**
- Write new material
- Revise existing text
- Add transitional elements
- Reorganize sequence
- Cut unnecessary parts

**Step 4: Verify Fix**
- Check logic flow
- Ensure consistency
- Test reader experience
- Confirm no new gaps
- Maintain story quality

### E08: SCENE DYNAMICS - TRD METHOD

#### THE TRD METHOD (Tension/Reversal/Dynamics)

**TENSION: Every scene needs conflict**
- [ ] Character wants something
- [ ] Obstacle prevents achievement
- [ ] Stakes are clear
- [ ] Urgency present
- [ ] Reader cares about outcome

**REVERSAL: Something must change**
- [ ] Character learns new information
- [ ] Situation shifts unexpectedly
- [ ] Power dynamics change
- [ ] Stakes escalate
- [ ] New problems arise

**DYNAMICS: Energy must flow**
- [ ] Scene starts with energy
- [ ] Energy builds through conflict
- [ ] Energy peaks at reversal
- [ ] Energy flows to next scene
- [ ] No energy leaks or dead spots

#### SCENE PURPOSE TEST

**Every Scene Must:**
- [ ] Advance plot OR reveal character
- [ ] Have conflict/tension
- [ ] Start late (in progress)
- [ ] End early (before resolution)
- [ ] Include sensory details
- [ ] Show character emotion
- [ ] Create questions
- [ ] Feel necessary
- [ ] Connect to scenes before/after
- [ ] Earn its word count

## CHAPTER 18: POWER PROMPTS & READER HOOKS

### E10: POWER PROMPTS - DIAGNOSTIC TOOLS

#### DIAGNOSTIC PROMPTS

**For Analysis:**
```
"Analyze this chapter using [specific criteria].
Identify the three biggest weaknesses and explain why."
```

**For Generation:**
```
"Generate [specific length] of [specific type]
following these parameters: [list]. Include [elements]."
```

**For Revision:**
```
"Revise this [text] to fix [specific problem]
while maintaining [what's working]. Keep the same length."
```

**For Comparison:**
```
"Compare these two versions. Which better serves [goal]?
Explain the specific strengths of each."
```

#### SURGICAL EDITS

**Fix Boring:**
```
"Add tension through: ticking clock, hidden agenda,
conflicting goals, or unexpected interruption."
```

**Fix Confusing:**
```
"Clarify: who's present, where we are, when this happens,
what's at stake, and why it matters."
```

**Fix Overwritten:**
```
"Cut 30% without losing meaning. Remove redundancy,
excessive description, and unnecessary dialogue."
```

**Fix Underwritten:**
```
"Add sensory details, internal monologue, and
physical reactions. Show the scene fully."
```

### E14: PACING MATRIX - RHYTHM MANAGEMENT

#### CHAPTER LENGTH STRATEGY

**Short Chapters (1500-2000 words):**
- High tension scenes
- Action sequences
- Quick revelations
- Cliffhanger endings
- Fast-paced sections

**Medium Chapters (2000-3000 words):**
- Character development
- Plot advancement
- Relationship building
- World-building
- Balanced pacing

**Long Chapters (3000-4000 words):**
- Complex scenes
- Multiple POVs
- Detailed exploration
- Climactic moments
- Resolution scenes

#### SCENE-SEQUEL PATTERNS

**Scene (Action):**
- Character pursues goal
- Meets obstacle
- Conflict occurs
- Outcome achieved
- New situation created

**Sequel (Reaction):**
- Character processes outcome
- Emotional response
- Decision about next action
- New goal established
- Transition to next scene

#### TENSION GRAPHS

**Rising Tension:**
- Start with small conflict
- Add complications
- Increase stakes
- Build to climax
- Peak at chapter end

**Varying Tension:**
- High tension scene
- Brief relief moment
- New tension introduced
- Escalation continues
- Satisfying resolution

## THE EDITING WORKFLOW

### ORDER OF OPERATIONS (Big to Small)

```
LEVEL 1: STRUCTURAL EDITING (Weeks 1-2)
Does the story work?
├─ Beginning hooks?
├─ Middle holds?
├─ Ending satisfies?
├─ Causality clear?
└─ Fix these FIRST

↓

LEVEL 2: CHARACTER EDITING (Week 3)
Do the people work?
├─ Motivations clear?
├─ Arcs complete?
├─ Voices distinct?
├─ Relationships earned?
└─ Fix these SECOND

↓

LEVEL 3: SCENE EDITING (Week 4)
Do the moments work?
├─ Each scene necessary?
├─ Tension present?
├─ Dynamics vary?
├─ Transitions smooth?
└─ Fix these THIRD

↓

LEVEL 4: LINE EDITING (Week 5)
Do the sentences work?
├─ Voice consistent?
├─ Flow natural?
├─ Clarity achieved?
├─ Style polished?
└─ Fix these FOURTH

↓

LEVEL 5: COPY EDITING (Week 6)
Are mechanics correct?
├─ Grammar proper?
├─ Spelling correct?
├─ Punctuation right?
├─ Format consistent?
└─ Fix these LAST
```

**NEVER EDIT BACKWARDS** (Don't polish sentences you might cut)
