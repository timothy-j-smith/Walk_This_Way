## 🧪 **BETA FEATURES**

### **Real-Time AI Suggestions:**
- **Enable**: Settings → AI → Beta Features → Real-time suggestions
- **Function**: AI provides suggestions as you type
- **Benefits**: Catch issues immediately, improve writing flow
- **Usage**: Type normally, AI suggests improvements in real-time
- **Customization**: Adjust suggestion frequency and types

### **Multi-File Context:**
- **Enable**: Settings → AI → Beta Features → Multi-file context
- **Function**: AI can reference multiple files simultaneously
- **Benefits**: Maintain consistency across chapters, better context
- **Usage**: Use @filename references in prompts
- **Limitations**: May increase response time with large files

### **Style Consistency Checker:**
- **Enable**: Settings → AI → Beta Features → Style consistency
- **Function**: Analyzes writing style across all files
- **Benefits**: Maintains consistent voice and tone
- **Usage**: Ask "Check my writing style consistency"
- **Customization**: Set style preferences and thresholds

### **Voice Recognition Integration:**
- **Status**: Limited availability, still in development
- **Function**: Voice-to-text input for writing
- **Benefits**: Faster input, hands-free writing
- **Usage**: Use external voice tools, import to Cursor
- **Alternatives**: Dragon NaturallySpeaking, built-in voice tools

## ⌨️ **KEYBOARD SHORTCUTS**

### **Essential Shortcuts:**
- **Cmd+K**: Inline AI editing
- **Cmd+L**: Open Claude chat
- **Cmd+I**: Inline chat about selected text
- **Cmd+P**: Quick file open
- **Cmd+F**: Find in current file
- **Cmd+Shift+F**: Find in all files

### **Advanced Shortcuts:**
- **Cmd+Shift+L**: Add more context to chat
- **Cmd+I**: Composer mode for multi-file edits
- **Cmd+\**: Split editor view
- **Cmd+B**: Toggle sidebar
- **Cmd+Tab**: Switch between open files
- **Cmd+W**: Close current tab

### **Custom Shortcuts:**
- **Create Custom**: Settings → Keyboard Shortcuts
