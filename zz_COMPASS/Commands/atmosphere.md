# ATMOSPHERE AND MOOD COMMAND

Create immersive atmosphere and mood based on the scene's emotional context:
- For DARK/THREATENING scenes: Use ominous weather, shadows, isolation, unsettling sounds
- For ROMANTIC/TENDER scenes: Use soft lighting, intimate spaces, gentle sensory details
- For TENSE/SUSPENSEFUL scenes: Use confined spaces, ticking clocks, environmental pressure
- For PEACEFUL/SERENE scenes: Use open spaces, natural beauty, calming sensory details
- Establish setting through period-specific elements (1970s Boston for your novel)
- Use symbolism and metaphorical language that matches the emotional tone
- Ground scenes in specific time and place with authentic historical details
- Create contrast between internal character state and external environment when appropriate
