# zz_COMPASS Archive

**Purpose:** Keeps enhancement-research and synthesis docs **out of the way** but **easy to find** — so you don’t duplicate work or re-run the same research.

**File naming:** Always add **dates at the beginning** of synthesis and research files: `YYYY-MM-DD_Description.md` (e.g. `2026-01-26_COMPASS_Enhancement_Research_Synthesis.md`). Sorts chronologically and keeps the archive scannable.

**What belongs here:**
- **COMPASS_ENHANCEMENT_RESEARCH_GUIDE.md** — How to run synthesis sessions (what to type, no special MCP command needed).
- **Completed synthesis outputs** — e.g. `2026-01-26_COMPASS_Enhancement_Research_Synthesis.md`, or “Research X – COMPASS synthesis,” so you can refer back and avoid redoing the same analysis.

**Example synthesis:** `2026-01-26_COMPASS_Enhancement_Research_Synthesis.md` — Merged January 2026 Cursor/novelist research + Ultra/MAS/Enhanced/Cognee-style passes.

**Template for syntheses:** `JAZZ_CHAT_ANALYSIS.md` (project root).

**When you have new research:** Add it in chat (paste or @), then say: *“Analyze this research and make recommendations for COMPASS — use the Enhancement Research Guide and JAZZ_CHAT_ANALYSIS as the template.”* No need to “initiate” an MCP — just ask for the analysis.
