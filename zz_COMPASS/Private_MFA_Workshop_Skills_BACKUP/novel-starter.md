# Novel Starter — Per-Project Workspace Kit

**When Timothy opens a new novel folder**, scaffold these files. The Private MFA Workshop skill travels automatically from `~/.cursor/skills/private-mfa-workshop/`.

Copy templates from [templates/](templates/) or generate from this guide.

---

## Folder Structure (Recommended)

```
[Novel Name]/
├── Story_Bible/
│   ├── 00_README.md
│   ├── 01_Synopsis_and_Acts.md
│   ├── 02_Chapter_Outline.md
│   ├── 03_Character_Depth_Hierarchy.md
│   ├── 04_Prose_DNA.md
│   └── 05_Geography_Brief.md          (if place matters)
├── Draft/
│   ├── Chapter_01_[Title].txt
│   └── ...
├── PARKING_LOT.md                      (deferred ideas — don't lose, don't chase)
├── .cursor/
│   └── rules/
│       └── novel-project.mdc           (optional: "This is Senseless — load case study")
└── tmp/                                (session summaries)
```

## Setup Checklist

```
Novel Setup Progress:
- [ ] Create folder + git init (if desired)
- [ ] Copy templates from private-mfa-workshop/templates/
- [ ] Fill 01_Synopsis_and_Acts.md (Architecture phase)
- [ ] Assign primary lens (O / D / K) — discuss with Professor
- [ ] Map POV ownership per chapter
- [ ] Build revelation calendar (what secrets, when planted, when detonated)
- [ ] Identify spine (one structural device — Senseless: Toothpaste Factory)
- [ ] Create PARKING_LOT.md
- [ ] First Brick: seed scene or image — do NOT polish yet
```

## Story Bible Minimum

### 00_README.md

- Novel title, logline, target word count
- Primary lens + guest authors expected
- Current A.B.S.H. phase
- Liberty Level default for this project stage

### 01_Synopsis_and_Acts.md

- 3-act summary
- Timelines (if nonlinear)
- Ending image (know where you're going)

### 02_Chapter_Outline.md

- Chapter titles + one-paragraph beat each
- POV owner per chapter
- Interludes/structural devices marked

### 03_Character_Depth_Hierarchy.md

| Tier | Characters | Depth |
| --- | --- | --- |
| 1 | Protagonist | Full interiority, arc, voice |
| 2 | Core cast | Scene-level specificity |
| 3 | Supporting | Function + one vivid detail |

### 04_Prose_DNA.md

- Sentence rhythm target
- Three writing modes priority for THIS book
- Money detail examples from early drafts
- Refrains to plant
- What to avoid (Timothy's tell-triggers for this project)

## PARKING_LOT.md Purpose

Ideas that are good but not for NOW. Prevents:

- Chasing shiny tangents mid-chapter
- Losing ideas that aren't ready
- Architecture creep during Brick phase

Format: date + idea + which act/chapter it might belong to.
