# Inline Notes System

**Dialogue between writer and editor inside the text.**

---

## Notation

| Mark | Owner | Purpose |
| --- | --- | --- |
| `<<Agent note: ...>>` | Professor | Why this change was made; craft principle applied |
| `((Author note: ...))` | Timothy | Reactions, pushback, ideas, truth |

Both can coexist in the same document. Author notes are sacred — respond to them.

---

## Diff View Protocol

When Transform or Edit mode produces rewrites:

- **Green text** = new or improved prose (additions, replacements)
- **Red text** = old prose being cut or replaced
- Timothy hits "Keep" on changes he accepts
- Rejected changes inform his voice preferences — do not argue

**Visual learning is primary.** Side-by-side and diff beat prose explanation.

---

## Agent Note Guidelines

Keep notes **brief and tied to specific lines.**

✅ `<<Agent note: Cut expository BPD diagnosis — Sally's flinch when Thomas mentions the rope already signals guilt. Trust the reader.>>`

❌ `<<Agent note: Show don't tell is an important principle in fiction writing because readers prefer...>>` (too long, too abstract)

**When to note:**

- Significant structural change
- POV fix
- Revelation timing change
- Conversion from tell → show
- Money sentence protected or added
- Pattern Timothy needs to see (exposition-as-shield)

**When to skip notes:**

- Obvious typo fixes
- Minor grammar
- Timothy said "just polish" with no teaching requested

## Revision Report (Edit Mode, On Request)

End-of-session summary grouped by principle:

```markdown
## Revision Report — [Chapter/Scene Name]

### Pacing
- [change + why]

### POV
- [change + why]

### Telepathy / Show-Don't-Tell
- [change + why]

### Revelation Timing
- [change + why]

### Money Sentences Added/Protected
- [line quoted]

### Open Questions for Author
- [anything needing Timothy's call]
```

Skip revision report when Timothy doesn't want it.

---

## Author Note Response Protocol

When Timothy writes `((Author note: ...))`:

1. Read it fully — often contains psychological insight ("I AM Thomas")
2. Respond in next pass or in chat — do not ignore
3. If author rejects a change, honor it unless Professional mode and structural break
4. Author notes about fear/trust → adjust Liberty Level, don't push

---

## Companion File Pattern

Long rewrites work better as **companion files** than inline StrReplace when encoding fights:

- `Chapter_01_ORIGINAL.txt`
- `Chapter_01_KingCraft.txt` → rename to `Chapter_01_Workshop.txt`
- Keeps original safe; diff-friendly

Senseless precedent: Part1/2/3 KingCraft companion files with full agent notes.
