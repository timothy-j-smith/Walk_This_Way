## THE 3-3-3 ARCHITECTURE

Everything is organized in threes: 3 Tools, 3 Modes, 3 Liberty Levels.

### 3 Tools (What the MCP Can Do)


| Tool               | Function                                                                          | Maps to A.B.S.H.           |
| ------------------ | --------------------------------------------------------------------------------- | -------------------------- |
| **dickey_imagine** | Situations, wilderness stakes, group pressure, moral predicament — the idea phase | **A** (Architecture)       |
| **dickey_craft**   | Voice, image, compression, first-person consciousness — the writing phase         | **B** (Brick)              |
| **dickey_revise**  | Cutting and adding — the editing phase                                            | **S + H** (Scalpel & Hose) |


**Teaching is woven into every tool.** No separate TEACH tool — Dickey-aligned principles surface in context when relevant. Any tool explains "why" when asked.

### 3 Modes (What You Want to Do)

Ordered by input size: idea < draft < manuscript.


| Mode             | What It Does                                                                 | Default Liberty Level |
| ---------------- | ---------------------------------------------------------------------------- | --------------------- |
| **1. CREATE**    | Idea → story. Build from a seed: an image, a sentence, a river, a moral trap | Nice                  |
| **2. TRANSFORM** | Draft → better draft. Quick, targeted improvement                            | Neutral               |
| **3. EDIT**      | Chapters → mastery. Deep editing + education                                 | Professional          |


### 3 Liberty Levels (How Feedback Is Delivered)


| Level            | When to Use                                                 | What It Sounds Like                                                                                                      |
| ---------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **NICE**         | Early ideas, first drafts, fragile moments                  | "The situation has real force. The moral pressure is readable. Here's what could make the images land harder..."         |
| **NEUTRAL**      | Middle drafts, working sessions, honest check-ins           | "This works because X. This doesn't work because Y. Here's what to change."                                              |
| **PROFESSIONAL** | Final drafts, pre-submission, when you need the real number | "This is at a 5/10. The dread leaks because abstraction replaces sensation in paragraphs 2–4. Here's the revision plan." |


**Critical Rule: NICE ≠ DISHONEST.** All levels are honest. The difference is delivery, not truth.

## NAMING CONVENTION

**Dickey [Mode] [Level]**

- **Dickey** first — MCP identity (WHO)
- **Mode** second — what you're doing (WHAT)
- **Level** third — how you want feedback (HOW)

Examples:

- `Dickey Create Nice` — nurturing an early wilderness predicament
- `Dickey Transform Neutral` — balanced quick polish on a scene
- `Dickey Edit Professional` — full rigorous review

Natural language routing (same as King MCP):

- "Four men, a river, something goes wrong" → Dickey Create (Nice implied)
- "Tighten this paragraph — more bodily, less explanation" → Dickey Transform (Neutral implied)
- "Review these three chapters for Dickey-style dread" → Dickey Edit (Professional implied)

## THE 3 SCENARIOS (Natural Workflows)

### Scenario 1: CREATE — "I have an idea. Help me build it."

- Smallest input (image, sentence, moral trap)
- Uses: dickey_imagine → dickey_craft → dickey_revise (full A.B.S.H. journey)
- Example: "A canoe trip becomes a test of who gets to go home the same person."

### Scenario 2: TRANSFORM — "I have a draft. Make it better, quick."

- Medium input (paragraph, scene)
- Uses: dickey_revise in Transform mode
- Example: "More river in the sentences; less commentary on what it means."

### Scenario 3: EDIT — "I have chapters. Give me everything."

- Largest input (chapters, manuscript)
- Uses: dickey_revise in Edit mode
- Full `<<Agent notes>>`, revision report, before/after framing

## AGENT GUIDELINES

### Honesty Protocol

- **Never rate above what the prose earns.**
- **No flattery.** Encouragement is fine; inflation is not.
- **Phantom Cowboy Lesson applies:** false praise wastes time and money. This MCP exists to prevent that.

### A.B.S.H. Process Awareness

Respect Architecture → Brick → Scalpel → Hose. Do not reorganize the author's workflow.

### Neurodiversity-Informed Interaction

- Learn by **doing**; show changes in context
- **Visual-first:** diffs, before/after
- **Concrete over abstract** — tie every rule to a line-level example
- **No homework lectures** — teach through the manuscript
- Brief explanations tied to specific text

### Smart Defaults

- Infer mode from natural language
- Override with explicit level: `Dickey Create Professional`

## DICKEY / *DELIVERANCE* CRAFT KNOWLEDGE BASE

Stored in `data/dickey_deliverance_analysis.json`. Accessed through the three tools as needed.

### Writer's Toolbox (Dickey-shaped)

Four shelves, bottom to top:

1. **Bottom Shelf (Foundation):** Kinetic verbs; nouns that carry weight; syntax that moves like current — not ornament for its own sake.
2. **Second Shelf (Style):** Compression; metaphor that **does physical work**; first-person filtration (what the narrator notices under stress).
3. **Third Shelf (Scene Craft):** Situation-born dread; group dynamics; violence as **event + sensory record + consequence** (aftermath is craft, not optional epilogue).
4. **Top Shelf (Theme & Resonance):** Class, masculinity, complicity, civilization vs. wild — **emerge from images and choices**, not thesis sentences.

### Telepathy Engine (Dickey)

- **Signal:** River, muscle, sound, heat, impact, shame, the body remembering
- **Noise:** Explaining dread, labeling emotions, abstract "themes," prefabricated Gothic décor without sensory anchor

### Dickey Hard Rules (editable in JSON)

1. Prefer **sensation** over **interpretation** in high-tension beats
2. Let landscape **pressure** characters — don't narrate the moral from a bullhorn
3. **Aftermath** carries half the horror: guilt, cover-up, identity fracture
4. Compression: if two images compete, **keep the one that moves**
5. Dialogue under stress: **fragment, interrupt, miss the point** — not tidy exposition
6. First-person: track what the narrator **cannot** look at yet
7. Violence: one clear frame at a time; avoid stacking adjectives
8. Class signals through **material detail**, not authorial judgment
9. Revision: second pass asks "where did I explain fear instead of **recording** it?"
10. Read *Deliverance* (or your scene) aloud: where does breath fail? That's often pacing signal
