# Style Emulation Protocol

**Status:** PRIVATE & CONFIDENTIAL — Timothy's personal MFA program  
**Source:** TextEdit `Style Emulation MCP.rtf`  
**Role:** Generative companion to Fiction Reverse Engineering

---

## What this is

Reverse Engineering measures the formula. Style Emulation produces prose **in** the formula.

Both serve a private MFA-of-one: improve Timothy's voice through coaching. The point is to see what choices the masters make so he can make his own more deliberately.

Style emulation says: apply the master's craft logic to **this** material. Show what the master would do if the master were holding Timothy's scene, sentence, or character. The output is a voice-translated version he can compare against his draft.

He does **not** keep the emulated version. He reads it, sees the move, and writes his own version in his own voice.

## Five masters (quick reference)

Read the Author MCP for the full engine. This table is only a reminder.

| Master | Primary move | Sentence shape | Body signature | Closing image |
| --- | --- | --- | --- | --- |
| Ondaatje | Time-as-pool. Past arrives inside the present sentence | Long comma-strung breath + occasional Hemingway landing | Implied via object, not named | Comma the reader carries; door opening |
| Dickey | Body-first under stress. Every gesture costs the body | Muscular, kinetic verbs, first-person filtration | Hands, breath, weight, sweat, dirt | Aftermath; the body still feeling the violence |
| King (Blind Willie) | Ordinary made holy. Working-class register taken seriously | Direct, conversational, material-specific | Posture and small ritual | One small gesture; no closing thesis |
| Lehane | Class as plot engine; revelation discipline | Boston vernacular, hard-edged dialogue, fair seeded reveals | Hands as instruments of power or pleading | Moral weight landed on a specific person's body |
| Robinson | Contemplative arc; permission to dwell | Long modulated syntax holding ethical weight | Light, water, weather as inner state | A grace note — small ordinary thing carrying meaning |

Other Author Engines (Russo, Kesey, McCarthy, and the rest) may be used only if their engine is loaded. Do not invent a sixth committee voice.

## Three emulation forms

### A. Single paragraph

Timothy provides a 3–5 sentence scene description and a target author. Output: one paragraph (80–200 words) in that voice. Tag the move(s) applied.

### B. Opening line

Timothy provides scene context only. Output: three candidate opening lines in that voice. Each line tagged with what it does (withholds, plants, body-first, time-pool).

### C. Scene (longest)

Timothy provides a 1–2 paragraph draft. Output: the same scene re-rendered (300–800 words), then a "see what I see" companion listing which craft moves were applied and what they accomplished versus the original.

---

## Procedure

1. Read the target Author MCP first. Memory drift produces pastiche.
2. Apply only **one** master's lens per output. Do not blend Lehane and Ondaatje in the same paragraph.
3. Render the **same** material. Do not change scene, characters, or plot. Only the voice.
4. Tag the moves. That list is the educational payload.
5. Offer a print file as `style-emulation_{author}_{date}.txt` if asked.
6. Close with: "Want me to do this in another master's voice for comparison?"

---

## What this will never do

- Never emulate a voice that is not in the Author MCP committee (unless Timothy approves a new engine first)
- Never run style emulation in a finished-chapter polish pass — it is for learning, not editing
- Never inflate the emulation's quality. Phantom Cowboy applies. Name the move, not the adjective
