## What this is

Fiction Reverse Engineering measures structure. This MCP asks the host model to render **Timothy's material** in one master's voice, tag the craft moves, then stop. He writes his own version after.

It reads the Author Engines (`AUTHOR_ENGINES/data/*.json`) plus the five-master signature table. It does not call Anthropic. It does not keep a formula database.
